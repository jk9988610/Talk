# 读书笔记

存放阅读过程中的摘要、批注、质疑与延伸思考。

## 适合放入此处

- 书籍章节摘要
- 原文精彩段落 + 个人批注
- 与作者观点的对话或反驳
- 读后行动清单或实践计划

## 建议 frontmatter 字段

```yaml
book_title: 书名
book_author: 作者
book_year: 出版年份    # 可选
reading_status: reading | finished | abandoned
```
