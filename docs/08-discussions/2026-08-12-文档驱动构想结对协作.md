# 文档驱动构想结对协作

> 讨论：Talk + CivSlice 项目采用的协作形式是什么？

## 名称

**文档驱动构想结对（Document-Driven Idea Pairing）**

或：**想法站里的设计研讨（Design Studio in an Idea Repo）**

## 流程

```
对话抛直觉/问题 → 一起推演 → 落成 Markdown 规范 → 合并 Talk
    → 启动语交给新对话 → CivSlice 实现
```

## 特征

| 特征 | 说明 |
|------|------|
| 对话即规格 | 产出是决策与结构，不是先写码后补文档 |
| 双仓分工 | Talk 孵化构想，CivSlice 实现产品 |
| 辩证推进 | 固定十维 ↔ 时代模板、打分 ↔ 可信度分离 |
| AI 接力棒 | AI-GUIDE + 启动语压缩上下文 |
| 分类落盘 | ideas / discussions / projects 各归其位 |

## 与 CivSlice 时间设计的对应

| 研究方法 | 产品体现 |
|----------|----------|
| 历史分期 | ① 时代段 Tab |
| 共时性比较 | ②½ 各国泳道时间轴 |
| 分层个案选择 | ② 国家/朝代过滤 |
| 历史语境化 | 时代维度模板 |
