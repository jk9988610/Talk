# 维基百科「中国历史」对 CivSlice 的启发

> 讨论来源：分析 [维基百科「中国历史」条目](https://zh.wikipedia.org/wiki/%E4%B8%AD%E5%9B%BD%E5%8E%86%E5%8F%B2) 对 Talk/CivSlice 文档与数据设计的启发。  
> 结论已沉淀至 [CivSlice 史料方法论与数据规范](../07-projects/2026-08-12-CivSlice-史料方法论与数据规范.md)。

## 维基条目的结构特点

该条目采用**王朝政治叙事线**：

```
史前 → 文明起源 → 夏商周 → 秦汉 → 三国两晋南北朝 → 隋唐五代
→ 宋辽金 → 元明清 → 民国 → 中华人民共和国
```

CivSlice 的十维雷达是**横向切面**，维基是**纵向讲故事**——两者互补，不是替代。

## 六点核心启发

### 1. 史料类型三分法

维基在「文明起源」明确区分：

| 类型 | 例子 | 可信度 |
|------|------|--------|
| 考古遗存 | 二里头、良渚、殷墟 | 高（需解读） |
| 后世文献 | 《史记》《竹书纪年》 | 中（有时代距离） |
| 神话传说 | 禹禅让、启杀益 | 低（政治叙事） |

并指出**信史连续纪年起点：公元前 841 年（共和元年）**。

**→ 已纳入数据规范**：快照增加 `evidenceTypes` 字段。

### 2. 主动呈现学术争议

维基多处标注「仍有争议」「学界大多不认为」：

- 夏朝是否存在、二里头是否等于夏
- 战国起点：前 475 / 前 403 等不同划分
- 「封建」在马克思主义 vs 西方史学中的含义差异
- 商纣王叙事「成书于周灭商之后，存在构建合法性倾向」

**→ 已纳入数据规范**：快照增加 `controversies` 字段；`historical_memory` 维度记录叙述立场。

### 3. 个别时段有多维专题写法

战国一节有独立小节「战国时期的制度、军事、经济与文化」——与十维思路最接近，但**极不均匀**（医学、日常、资源几乎不独立成段）。

**→ CivSlice 价值**：每个快照强制十维填充或标 `absent`；维基作素材来源，不作结构模板。

### 4. 文明起源的阶段框架

维基采用中华文明探源工程的「古国时代」三阶段 + 王朝时代，比单纯「夏朝」更科学。

**→ 已纳入时代命名规范**：前 841 年以前优先考古文化名。

### 5. 反驳错误假说的写法

「外来说」专节（彩陶西来说、古巴比伦分支说、青铜技术西来说）逐一列出再反驳。

**→ 已纳入数据规范**：`rejectedHypotheses` 字段。

### 6. 参考文献模式

关键论断有脚注，引用考古报告、学术论文、出土文献。

**→ 已纳入数据规范**：`sources` 升级为结构化对象（含 `type`、`ref`、`note`）。

## 维基与 CivSlice 的差距（= 产品机会）

| 维度 | 维基百科 | CivSlice 补什么 |
|------|----------|----------------|
| 结构 | 王朝时间线 | 每时段十维雷达切面 |
| 可信度 | 隐式（脚注） | 显式四级标注 |
| 医学 | 几乎不涉及 | 独立维度，可标 absent |
| 日常生活 | 零散提及 | 系统记录 |
| 资源/环境 | 灾害偶现 | 独立追踪 |
| 历史记忆 vs 史实 | 混在一起 | 拆分关注 |
| 跨文明对照 | 偶尔一句 | 未来同期比较 |
| 数据化 | 纯文本 | 可计算、可可视化 |

## 从维基提取十维的优先级

| 维度 | 维基丰富度 | 补充来源 |
|------|-----------|----------|
| 技术、军事、政治、经济 | 高 | 可直接提取，须标 confidence |
| 社会文化 | 中 | 思想史、宗教史 |
| 地理、生产 | 中 | 历史地理、农业史 |
| 资源、日常生活、医学 | 低 | 须另找专题史或标 absent |
| 历史记忆 | 混在叙事中 | 须主动分离「叙述」与「史实」 |

## 核心结论

> 好的历史叙述 = 政治叙事 + 史料批判意识 + 争议透明化

CivSlice 的任务是把维基**隐式具备**的批判精神，变成**显式结构化**的十维数据。
