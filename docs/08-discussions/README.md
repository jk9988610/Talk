# 开放讨论

存放待探讨的议题、辩题与命题，旨在征集多元观点而非给出定论。

## 适合放入此处

- 「是否应当…」类价值判断题
- 「A 与 B 孰优孰劣」类比较题
- 尚无共识的行业或社会议题
- 需要不同背景读者回应的开放问题

## 写作提示

- 在文首清晰陈述**讨论命题**
- 列出你已有的立场与理由（如有）
- 明确欢迎哪些类型的回应
- 避免将讨论帖写成已定结论的随笔
