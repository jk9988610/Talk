# CivSlice 时代维度模板

> 实现仓库：[CivSlice](https://github.com/jk9988610/CivSlice)  
> 关联：[数据规范](2026-08-12-CivSlice-史料方法论与数据规范.md) · [对比雷达与派生指标](2026-08-12-CivSlice-对比雷达与派生指标.md) · [区域导航与比较选择](2026-08-13-CivSlice-区域导航与比较选择.md)

## 问题

固定十维（地理、技术、经济、政治……）贯穿所有时代，会导致：

| 错位示例 | 问题 |
|----------|------|
| 旧石器时代谈「货币贸易」 | 维度无意义 → 只能标 absent |
| 古代谈「数字化」「公共卫生体系」 | 用现代概念套古代 |
| 现代只谈「青铜礼器」 | 低估当代维度 |
| 跨时代纵向比较同一轴 | 「经济 3」在公元前 500 与 1950 含义完全不同 |

> **现代维度不适用古代，古代维度也不足以描述现代。**

## 设计原则

1. **同时代横向比较** — 同一快照年份的文明，应使用**同一套时代模板**（否则无法对比）
2. **跨时代纵向浏览** — 允许模板切换，UI 明确标注「维度集已变更」
3. **核心 + 时代模块** — 少数跨时代通用核心 + 多数时代专属字段
4. **对比雷达不变** — 派生指标（动员力、创新力…）仍从当前模板字段计算，保持跨文明可比
5. **不删史料** — 模板切换是展示层重组，原始记录仍可按规范存档

---

## 三层结构

```
┌─────────────────────────────────────────┐
│  核心维（Core）— 所有时代必有，定义随时代注释  │
├─────────────────────────────────────────┤
│  时代模块（Era Module）— 该时期专属维度        │
├─────────────────────────────────────────┤
│  派生指标（Stats）— 从核心+模块计算，用于对比雷达 │
└─────────────────────────────────────────┘
```

---

## 时代分期（模板切换点）

按生产力与组织形态划分，与王朝纪年解耦：

| 模板 id | 名称 | 大致年份 | 特征 |
|---------|------|----------|------|
| `paleolithic` | 石器时代 | 前 1 万以前 | 采集、小群体、石骨器 |
| `neolithic` | 新石器/早期农业 | 前 1 万 — 前 4000 | 农业萌芽、定居、陶器 |
| `bronze` | 青铜时代 | 前 4000 — 前 1000 | 青铜、早期国家、文字 |
| `iron_imperial` | 铁器与帝国 | 前 1000 — 1500 | 铁器、帝国、官僚、古典文化 |
| `early_modern` | 近代早期 | 1500 — 1800 | 火器、殖民、印刷、民族国家萌芽 |
| `industrial` | 工业时代 | 1800 — 1945 | 机械化、工业化、民族国家 |
| `contemporary` | 当代 | 1945 — 今 | 信息化、全球化、现代国家 |

快照绑定模板：

```json
{
  "year": -2500,
  "eraLabel": "二里头文化",
  "eraTemplate": "bronze",
  "dimensions": { }
}
```

`eraTemplate` 由 `year` 自动推断，也可手动覆盖（边缘年代）。

## 核心维（5 项，全时代）

名称不变，**评分 rubric 随模板变化**（文档注明）。

| id | 名称 | 全时代含义 |
|----|------|-----------|
| `geography` | 地理气候 | 生存空间与地缘约束 |
| `subsistence` | 生计来源 | 获取食物与基本物资的方式（原「资源+生产+日常」的底层） |
| `organization` | 社会组织 | 权力结构、分工、动员方式（原「政治+生产组织」底层） |
| `knowledge` | 知识技术 | 工具、方法、信息记录（原「技术」扩展） |
| `culture` | 文化认同 | 信仰、艺术、教育、身份（原「社会文化」） |

核心维保证纵向浏览时始终有五根「粗轴」，不会因模板切换完全失联。

## 时代模块维（每模板 4–5 项）

## 与旧十维的映射（迁移用）

| 旧十维 | 新结构 |
|--------|--------|
| geography | 核心 `geography` |
| resources | 核心 `subsistence` + 时代模块（如 `trade`） |
| technology | 核心 `knowledge` + 模块（`metallurgy` / `industry` 等） |
| production | 核心 `organization` + `subsistence` |
| economy | 时代模块 `trade` / `commerce` / `global_integration` |
| politics | 核心 `organization` + 模块 `state_formation` / `bureaucracy` |
| military | 时代模块 `military` / `firearms` |
| culture | 核心 `culture` |
| daily_life | 核心 `subsistence` |
| historical_memory | 时代模块 `historiography`（古代+）或 `culture` note |

旧 `china.json` 可保留十维，CivSlice 用映射表转换为新模板展示；新数据直接按模板填写。

## 比较规则

### 同一 year 横向比（文明互卡）

- **必须**使用相同 `eraTemplate`
- 剖面雷达轴 = 该模板的核心 + 模块
- 对比雷达派生指标从同一模板字段计算

### 跨 year 纵向比（同一文明兴衰）

- 模板随年代切换，UI 提示：「公元前 500 年与 1950 年维度集不同，不宜直接叠图」
- 可选「仅看核心五维」模式做粗线条纵向对比
- 对比雷达派生指标可纵向比（因公式从当前模板归一化）

### 跨时代文明对战（娱乐）

- 不推荐严肃比较；若做「文明 FIFA」类娱乐，仅用**对比雷达派生指标**，不用剖面十维

## 数据模型扩展

```json
{
  "meta": {
    "eraTemplates": {
      "bronze": {
        "label": "青铜时代",
        "yearRange": [-4000, -1000],
        "core": ["geography", "subsistence", "organization", "knowledge", "culture"],
        "modules": ["metallurgy", "writing", "state_formation", "ritual_order", "trade"]
      }
    }
  },
  "snapshots": [{
    "year": -2500,
    "eraTemplate": "bronze",
    "dimensions": {
      "geography": { "level": 3, "summary": "…", "confidence": "documented" },
      "metallurgy": { "level": 3, "summary": "…", "confidence": "inferred" }
    }
  }]
}
```

`dimensions` 的 key 须属于该快照 `eraTemplate` 的 core + modules；其他 key 忽略或标为迁移遗留。

## 派生指标公式调整

派生指标权重表按 `eraTemplate` 分版，或统一从「核心五维 + 当前模块中能映射的项」计算。

示例（bronze 时代 `innovation`）：

```
innovation = f(knowledge, metallurgy, writing)  // 权重见 stats.js
```

示例（contemporary 时代 `innovation`）：

```
innovation = f(knowledge, industry, information, education)
```

`stats.js` 结构：

```javascript
const STAT_WEIGHTS_BY_ERA = {
  bronze: { innovation: { knowledge: 0.4, metallurgy: 0.35, writing: 0.25 }, ... },
  contemporary: { innovation: { knowledge: 0.3, industrial_capacity: 0.35, information: 0.35 }, ... },
};
```

## UI 提示

- 快照卡片显示：`时代模板：青铜时代`
- 纵向拖动跨越模板边界时，顶部横幅：「维度集已切换至铁器帝国时代」
- 剖面雷达轴标签用当前模板字段名；hover 显示 rubric 说明

| 阶段 | 内容 |
|------|------|
| P1 | 定义 7 套模板 JSON + `inferTemplate(year)` |
| P2 | 中国快照迁移：bronze / iron_imperial / contemporary 三套试点 |
| P3 | 剖面雷达按模板动态生成轴 |
| P4 | `stats.js` 分时代权重 |
| P5 | 旧十维 → 新模板自动映射层（兼容） |

## 开放问题

1. 边缘年份（如 1500）模板归属 — 允许 `early_modern` 手动覆盖
2. 区域差异（美洲青铜时代缺失）— 模板全局 vs 区域变体
3. 核心五维 rubric 文档工作量 — 需分时代写评分说明
