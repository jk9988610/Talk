# 征服三国 · TCG 卡牌框架总览

> **实现仓库**：[Conquer-the-Three-Kingdoms](https://github.com/jk9988610/Conquer-the-Three-Kingdoms)（未从 Talk 正式孵化流程出规格，属 L2 关联项目）  
> **在线**：[jk9988610.github.io/Conquer-the-Three-Kingdoms](https://jk9988610.github.io/Conquer-the-Three-Kingdoms/)

---

## 定位

**TCG 尺寸标准**的卡牌游戏**前端框架**：Vite + TypeScript；卡面为程序绘制的像素画 + 文本层；带商店、战场、手牌拖拽与 MIDI 风格背景音乐（Web Audio，无外部音频文件）。

---

## 卡牌规格

| 项 | 值 |
|----|-----|
| 标准尺寸 | 宽 63.5 × 高 88.9（逻辑单位，等比缩放） |
| 内框边距 | 左右 3%，上下 4% |
| 卡面分层 | 像素图像层（Canvas 绘制）+ 文本层（名称、描述） |

---

## 界面区域

| 区域 | 阶段 | 说明 |
|------|------|------|
| 上半 | 准备 | **商店** |
| 上半 | 战斗 | **敌方战场** |
| 下半 | 全程 | **我方战场**（拖拽角色上场） |
| 手牌区 | 全程 | 我方手牌 |
| 预留 | — | 装备/物品（待实现） |

---

## 当前可玩内容

- 手牌含 **吕布** 等角色；**仅拖拽**上场（避免长按选中文字）
- 玩家初始 **1000 金币**
- 商店：**治疗药水**（30 金，治疗 20）、**方天画戟**（100 金，+10 攻击）
- 像素画：吕布、药水、方天画戟等均由代码绘制
- 背景音乐：内嵌 MIDI 风格音符数据

---

## 技术栈与开发

```bash
npm install
npm run dev -- --host 0.0.0.0   # Termux 真机调试
```

| 层 | 选型 |
|----|------|
| 构建 | Vite 5（Termux 若 `Illegal instruction` 用 `vite@5.4.11`） |
| 语言 | TypeScript |
| 部署 | GitHub Actions → Pages |
| 后端 | `supabase/` 目录存在，与 Card-World 生态可扩展 |
