# MiraSpace 科学阶段路线图

> **父文档**：[米拉空间数字生命演化](2026-08-14-米拉空间数字生命演化.md)  
> 本文档定义**为何**这样划分阶段、各阶段的**科学问题**与**涌现门槛**。实现规格按阶段另文撰写。

## 为何不采用「RNA → DNA → 细胞 → 多细胞」作为工作计划

教科书叙事常把地球生命史压缩成分子名称的线性链条，但这**不适合**作为模拟工程的阶段切分，原因如下：

| 问题 | 科学说明 |
|------|----------|
| **DNA 不是「细胞之前」的独立一步** | 在地球历史上，更可靠的顺序是：可复制的信息分子（RNA 假说）→ **原细胞/膜分隔** → 在已有细胞框架内出现更稳定的信息存储（DNA）。把 DNA 放在「细胞之前」是简化图示，不是工作依赖关系。 |
| **复制子路线 vs 代谢路线尚未定论** | 「复制子优先」（Pross, Eigen）与「代谢/自催化优先」（Kauffman, Wächtershäuser）仍是并存假说。阶段规划应允许**两条路竞争涌现**，而非预设 RNA 必定最先出现。 |
| **里程碑名称 ≠ 涌现功能** | 模拟目标是实现**功能前提**（遗传、变异、选择、边界、耦合），而非在代码里命名出「RNA 实体」。 |
| **工程层与生物层混杂** | 画布、坐标系、观察者是**观测基础设施**，不属于生命起源科学阶段；须与生物涌现阶段分开编号。 |

**结论**：米拉空间以**功能前提 + 可测量涌现门槛**划分阶段；RNA、DNA、原核/真核等仅作**地球参照注解**，不作实现里程碑名称。

## 阶段划分原则

1. **按必要功能排序** — 下一 stage 的模块在科学上依赖上一 stage 已涌现的能力（或并行假说在文档中显式标注）。
2. **门槛可审计** — 每阶段结束须定义可量化指标 + 持续时长 + 对照实验（改 seed / 关模块）。
3. **涌现优先** — 禁止「到阶段就 spawn 对应分子/细胞」；仅允许**开放**新的交互规则与底物类型，由模拟产生结构。
4. **模仿而非仿真** — 参照地球生命的**角色**（复制误差、膜、代谢耦合），不追求真实化学动力学。
5. **先平台后生物** — **P0** 完成观测与 tick 基础设施后，再进入 **S1** 生物底物。

### 与 NASA 生命定义的对应

NASA 工作定义：*能够进行达尔文演化的、自维持的化学系统*。

| NASA 要素 | 米拉空间对应阶段 |
|-----------|------------------|
| 化学系统（物质与环境） | **S1** 远离平衡态底物 |
| 达尔文演化（遗传 + 变异 + 选择） | **S2** 达尔文阈值 |
| 自维持 + 系统边界 | **S3–S4** 原细胞 → 整合细胞 |
| （定义未涵盖但本项目扩展）多细胞协作 | **S5** |

## 总览：P0 + S1–S5

```
P0  观察基底          工程：Canvas · 坐标 · 观察者 · 模拟时钟
         ↓
S1  远离平衡态与前生物复杂性   科学：持续通量 · 自催化 · 尚无可遗传信息
         ↓ 涌现：负熵维持 + 自催化网络稳定
S2  达尔文阈值          科学：模板复制 · 突变 · 种群选择（复制子/代谢子均可）
         ↓ 涌现：跨代际可遗传变异 + 适应度分化
S3  个体化与原细胞        科学：膜状边界 · 内外 compartment · 分裂
         ↓ 涌现：边界内复制子富集 · 裸复制子劣势
S4  整合细胞单元         科学：代谢–遗传–边界耦合（化学子模型）
         ↓ 涌现：自维持复制单元 · 稳定谱系（DNA 式存储可在此涌现，非独立阶段）
S5  多细胞性            科学：持久细胞间绑定 · 分工 · 发育式模式
```

| 编号 | 名称 | 核心科学问题 | 地球参照（仅注解） | 涌现门槛（摘要，详参 §各节） |
|------|------|--------------|-------------------|------------------------------|
| **P0** | 观察基底 | 如何稳定观测一片数字空间？ | — | 横屏 pan + 固定 tick + Pages 可访问 |
| **S1** | 远离平衡态与前生物复杂性 | 无序中能否维持秩序与自催化？ | 前化学汤、热泉、耗散结构 | 负熵流 + 自催化得分持续超阈 |
| **S2** | 达尔文阈值 | 何时出现可进化实体？ | RNA 世界、准物种、复制子竞争 | 可遗传度 + 谱系适应度分化 |
| **S3** | 个体化与原细胞 | 复制子如何被「个体」包被？ | 脂质囊泡、原细胞模型 | 膜内复制子富集 · 分裂事件 |
| **S4** | 整合细胞单元 | 代谢与遗传如何共演化？ | LUCA、化学子（chemoton） | 耦合单元自维持 · 谱系稳定 |
| **S5** | 多细胞性 | 细胞为何长期协作？ | 多次独立起源的多细胞 | 持久多细胞体 + 分工指标 |

## P0 — 观察基底（工程阶段）

**性质**：非生物学阶段；为所有后续模拟提供可重复观测环境。

| 项 | 要求 |
|----|------|
| 画布 | 全屏 Canvas；手机/平板横屏优先 |
| 坐标 | 世界坐标 ↔ 屏幕坐标；Y 向上 |
| 观察者 | 单指平移；不操控生物 |
| 时钟 | 固定 Δt 模拟 tick，与渲染分离 |
| 世界 | 有界或周期边界；可暂停 |

**完成定义**：空世界上可漫游、tick 稳定、GitHub Pages 可访问。  
**详细规格**：[MiraSpace 阶段 0 — 空域、坐标与观察者](2026-08-14-MiraSpace-阶段0-空域坐标与观察者.md)（含 P0 与 S1 起步实现）。

## S1 — 远离平衡态与前生物复杂性

### 科学背景

生命前的地球系统处于**远离平衡态**：能量通量（太阳、地热、化学梯度）驱动物质循环。此阶段可能出现：

- **耗散结构**（Prigogine）— 秩序依赖持续能量流；
- **自催化集合**（Kauffman）— 分子网络自我放大，但尚无可模板复制的数字式遗传；
- **前生物聚合物** — 短链、随机序列，可参与反应但不构成进化。

### 米拉空间功能目标

- 标量/矢量场：`energy`、`waste` 等，维持**非平衡**；
- 粒子底物：单体、催化剂、短链聚合物（**无序列模板复制**）；
- 可选：代谢优先路径的**循环反应网络**（非复制子）。

### 涌现门槛（进入 S2 的必要条件）

| 指标 | 含义 | 示意阈值（可调 preset） |
|------|------|-------------------------|
| `negentropyFlux` | 系统负熵流是否持续（相对初始） | 60 s 滑动平均 > 基线 ×1.3 |
| `autocatalyticScore` | 自催化 vs 全局平均生成率 | > 1.2 持续 60 s |
| `complexityIndex` | 反应网络/粒子类型多样性非 trivial | 高于随机对照 seed |

**明确不算 S1 完成**：出现跨代遗传、模板复制、膜封闭个体。

### 与复制子路线的关系

S1 须足够丰富，使 S2 **有可能**涌现，但不保证唯一路径。若代谢优先路径先产生稳定循环，S2 文档须定义其如何携带**可遗传变异**（见 S2 双路径）。

## S2 — 达尔文阈值（可遗传变异的复制）

### 科学背景

「生命」与「非生命」在操作上的分界常落在**达尔文演化**是否成立：

- **遗传** — 子代相关性状与亲代相关；
- **变异** — 复制/分裂非完美；
- **选择** — 环境导致适应度差异并反馈到频次。

Eigen **准物种**与**错误阈值**：突变率过高则信息无法积累——S2 须能观察此现象，而非绕过。

### 米拉空间功能目标

开放**通用复制子机制**（不命名 RNA）：

- 线型（或图式）**信息串** + 模板匹配复制 + 突变率参数；
- **种群**级统计，禁止 singleton 脚本实体；
- 可选：**代谢子**携带可变异「规则表」而非序列（代谢优先路径）。

### 涌现门槛（进入 S3）

| 指标 | 含义 |
|------|------|
| `heritability` | 亲–子性状相关 > 阈 |
| `selectiveSweep` | 适应度方差驱动频次变化（可观测谱系） |
| `informationAccumulation` | 在错误阈值内，信息串长度或规则复杂度可累积 |

**地球参照**：RNA 世界、复制子竞争实验（Szostak 系）。**实现不必出现碱基字母**。

### 非目标

- 不把 DNA 双链作为 S2 交付物；
- 不预设「必须先有 RNA 再有膜」— S3 可与 S2 部分重叠探索（见 §并行假说）。

## S3 — 个体化与原细胞

### 科学背景

裸复制子面临：

- **寄生序列**（Eigen）— 短、复制快、无功能；
- **稀释** — 有益产物扩散至环境；
- **耦合问题** — 复制与代谢须在同一 **compartment**。

**膜状边界**（或米拉空间中的闭合曲线/区域）提供个体化：内外扩散系数差异、内环境浓缩。

### 米拉空间功能目标

- 可形成、生长、**分裂**的边界结构（2D 闭合边界即可）；
- 边界内/register 复制子与代谢粒子；
- 分裂时**非完美分配**（变异来源之一）。

### 涌现门槛（进入 S4）

| 指标 | 含义 |
|------|------|
| `encapsulationGain` | 膜内复制子/代谢物浓度 vs 外液 |
| `parasiteLoad` | 裸复制子占比下降 |
| `fissionEvents` | 稳定分裂频率（非人为触发） |

**地球参照**：脂质囊泡、原细胞实验室模型（Szostak, Hanczyc）。

---

## S4 — 整合细胞单元（化学子）

### 科学背景

Gánti **化学子（chemoton）** 三子系统：

1. **代谢子** — 物质能量转换循环；
2. **膜子** — 边界与物质交换；
3. **遗传子** — 信息复制与调控。

三者**耦合**后才算稳定「细胞级」单元，而非三个独立模块硬拼。

### 米拉空间功能目标

- 三子系统共享适应度（分裂成功 = 三者协同结果）；
- **自维持**：代谢通量 + 膜完整性 + 遗传复制在阈值内同时维持；
- **信息存储升级**（地球上是 DNA/RNA 保真度差异）可作为**涌现属性**出现，触发条件写入 preset，**不设独立「DNA 阶段」**。

### 涌现门槛（进入 S5）

| 指标 | 含义 |
|------|------|
| `chemotonCoherence` | 三子系统同步维持时长 |
| `lineagePersistence` | 谱系在环境扰动下存活代数 |
| `storageFidelity` | （可选）高保真存储涌现时记录，非必达名 DNA |

**地球参照**：LUCA、原核细胞；真核化（内共生）**不在本路线图必达范围**，可列未来扩展。

---

## S5 — 多细胞性

### 科学背景

地球上多细胞**多次独立起源**（动物、植物、真菌等），无单一「必然路径」。共同功能特征：

- 细胞间**持久 adhesion**；
- **分工**（生殖/体细胞、不同代谢角色）；
- **发育式**空间模式（由简单规则重复产生结构）。

### 米拉空间功能目标

- 分裂后细胞保持连接或明确重新聚合规则；
- 细胞间信号/资源交换；
- 适应度在**个体（多细胞体）**层面计算。

### 涌现门槛（项目 v1 完成）

| 指标 | 含义 |
|------|------|
| `multicellularPersistence` | 多细胞体存活时间 vs 单细胞对照 |
| `divisionOfLabor` | 细胞类型或行为异质性 + 功能相关 |
| `developmentalPattern` | 非随机空间排列可重复出现 |

## 并行假说与文档策略

| 假说 | 在米拉空间中的处理 |
|------|-------------------|
| 复制子优先 | S2 开放序列复制子 → S3 膜包被 |
| 代谢优先 | S1 强化自催化循环 → S2 携带可变异代谢规则表 |
| 膜与复制子共演化 | S2/S3 允许部分重叠开发，但**门槛须分别可测** |
| DNA 存储 | 作为 S4 **涌现子类型**，不单独占阶段编号 |

每开启一条新路径，须在 Talk 增补**对照指标**与**失败模式**（如错误阈值崩溃、寄生占满种群）。
