## 一、分层体系

```
Talk（文档中枢）
  ├── 核心孵化项目 — 有完整规格 + 独立实现仓 +（多数）Pages
  ├── Mira 宇宙 — 数字生命 / 小镇演绎 / Agent 导演
  ├── 游戏与实验 — 可玩原型或框架，文档待补
  └── 工具与早期 — 密钥、OTA、竞赛等辅助仓
```

| 层级 | 含义 | Talk 职责 |
|------|------|-----------|
| **L0 中枢** | Talk 本仓 | 构想、方法论、Agent 提示词、仓库导航 |
| **L1 孵化** | 从 Talk 出规格，独立仓实现 | 保留总览与变更联动（见 AI-GUIDE） |
| **L2 关联** | 共用 Supabase / 技术栈，未从 Talk 孵化 | 在总览中标注依赖关系 |
| **L3 实验** | 早期小游戏、音乐站等 | 仅列目录，待有兴趣时再写构想 |
