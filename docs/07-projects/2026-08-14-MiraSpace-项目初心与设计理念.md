# MiraSpace 项目初心与设计理念

> **用途**：防止在长期迭代中忘记「我们在做什么」；指导 Talk 写规格、MiraSpace 写代码、以及**环境—报告—迭代**该怎么转。  
> **关联**：[米拉空间数字生命演化](2026-08-14-米拉空间数字生命演化.md) · [科学阶段路线图](2026-08-14-MiraSpace-科学阶段路线图.md)

---

## 三句话初心

1. **看涌现，不演里程碑** — 不用脚本在某一分钟「生成 RNA / 细胞」。  
2. **你是观察者，不是育种员** — 玩家单指漫游；不默认上帝模式改个体。  
3. **Talk 定「什么叫出现了」，MiraSpace 负责「别作弊地让它可能发生」。**

---

## 我们在做什么

在一片可观察的 **2D 数字空间**里，用尽量少的局部规则，看**像生命一样的行为是否会自己长出来**：

- 原始汤里的秩序（S1）  
- 可遗传、可选择的复制子（S2）  
- 膜泡包被与分裂（S3）  
- 代谢—遗传—边界耦合的细胞式单元（S4，待做）  
- 多细胞协作（S5，待做）  

地球生命史是 **参照系**，不是施工顺序表（见路线图 §为何不采用 RNA→DNA→细胞）。

---

## 为什么这样做

| 动机 | 说明 |
|------|------|
| **好奇** | 复杂性是设计出来的，还是在规则+环境下 **涌现** 的？ |
| **诚实** | 若「生命出现了」，须能用指标与 headless 报告 **审计**，而非叙事 |
| **体验** | **静观型 aquarium** — 拖动、观看、读 HUD；不是操作型育种游戏 |

## 环境—报告—迭代：该怎么做

### 合法循环

```
调 preset / 规则（能量、突变率、成核率、膜通透…）
    → 跑模拟（后台脚本 / lab 页 / CI）
    → 读报告（指标、失败模式）
    → 改 preset 或机制（Talk 改阈 / MiraSpace 改代码）
```

这是在 **塑造世界**，不是塑造某一只生物。

### 禁止循环

| 禁止 | 原因 |
|------|------|
| 根据报告 **spawn 赢家** strand / vesicle | 破坏涌现，实验作废 |
| 手动改某个个体的 sequence | 同上 |
| 「到阶段就解锁动画生成实体」 | 脚本预演，非模拟 |

**纪律**：报告用于 **调环境、调规则、调指标定义**；不用于 **点名改 genome**。

---

## 鸡生蛋、先有复制还是先有膜

真实史上无简单答案。项目用 **程序机制** 自洽，避免哲学 paralysis：

| 机制 | 作用 |
|------|------|
| **功能分阶段** | S2=达尔文；S3=边界；S4=耦合 — 非分子名牌 |
| **开发门 / 结案门** | 机制可信即可做下一阶段；sustained 达标再「科学结案」 |
| **指标作操作定义** | 不争论「算不算生命」，而问 `heritability`、`encapsulationGain` 等 |
| **裸复制与膜共存** | S3 不要求裸 strand 消失；用 `parasiteLoad` 等观测趋势 |
| **DNA 不单独占阶段** | 高保真存储若出现，算 S4 涌现属性 |

## 三层心智模型

```
体验层  观察者漫游、HUD、sparkline     → 玩家感受
实验层  preset、后台跑、复制报告       → 维护者 / 你 决策
规范层  Talk 阶段、指标、禁止作弊      → AI 施工纪律
```

复杂哲学沉在 **规范层**；日常只在 **实验层** 转 preset；**体验层** 永远不把玩家变成上帝。
