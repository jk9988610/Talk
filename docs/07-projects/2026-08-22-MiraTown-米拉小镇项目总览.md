# MiraTown 米拉小镇 · 项目总览

> **已孵化** — 实现仓库：**[MiraTown](https://github.com/jk9988610/MiraTown)**  
> **权威规格**在实现仓 [`docs/MIRA-TOWN-SPEC.md`](https://github.com/jk9988610/MiraTown/blob/main/docs/MIRA-TOWN-SPEC.md)（合并版 L0–L7 + ADR）；本文档为 Talk 侧摘要与导航。

---

## 问题

如何做一个**网页演绎游戏**：用户（或 AI）提供剧本封面，引擎在**数学规范化的二维世界**里精确执行路径、碰撞、动画与镜头——而不是让 AI 直接操控坐标或生成不可校验的自然语言逻辑？

## 方案一句话

**AI 只写剧本（DSL）** + **程序精确执行** + **固定实体目录（catalog）** + **地图编辑器导出 YAML**。

---

## 三条铁律

| # | 原则 |
|---|------|
| 1 | **AI 只写剧本** — 路径、碰撞、动画、镜头插值由引擎实现 |
| 2 | **一切可检索、可校验** — 固定结构，可索引角色/场次/指令 |
| 3 | **空间是数学对象** — 坐标、尺寸、时间均为数值 |

---

## 核心概念

| 概念 | 说明 |
|------|------|
| **世界单位 (wu)** | 逻辑坐标，1 wu = 32 px；原点左下角；精度 0.01 |
| **视口** | 1280×720；场景 tick 60 Hz |
| **实体目录** | `catalog/entities.yaml` — 角色尺寸、动画集、道具 |
| **剧本 DSL** | `dsl_version: 1.0`；`.mira` 文本；lint 后播放 |
| **地图** | 编辑器绘制人行道与物件 → 导出 YAML 融入项目 |
| **Gate 0–3** | 协议冻结 → 运行时语义 → 体验交付 → AI 循环（均已闭合） |

### MVP 验收（来自规格）

- 输入：`title` + `theme` + `synopsis`（≥20 字）
- 输出：通过 Linter 的 `.mira` 剧本
- 规模：≥2 角色、1 场景、≥1 次镜头切换；时长 30–120 秒
- **无 AI 模式**（必需）：加载 `examples/minimal-play.mira` 或粘贴剧本 → lint → play

### 明确排除

AI 不调 API（播放时）、指令行不含自然语言、播放中不可改逻辑、无多人在线、无移动端（当前）。

## 技术架构

| 层 | 选型 |
|----|------|
| 单体仓 | npm workspaces：`packages/core`（运行时 + lint）+ 前端 |
| 前端 | Vite；播放页 + `/editor` 地图编辑器 |
| 剧本 | `.mira` + YAML 地图；`examples/template.mira` 为空白模板 |
| 测试 | `npm test -w @miratown/core` |
| 部署 | GitHub Actions → Pages |
