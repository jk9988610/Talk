# 多维文明历史可视化

## 问题

观看国家/文明历史讲解视频时，往往按**叙事线**（王朝更替、战争、人物）展开，难以同时把握该文明在**科技、经济、医学、人文、食物、历史自觉、地理、生产、资源**等维度上的状态，更难以在**同一时间截面**上横向比较不同文明。

## 核心设想

用**时间线驱动**的交互页面，在选定年代展示一个或多个文明的「九维快照」：

| 维度 | 关注什么 |
|------|----------|
| 科技 | 工具、建筑、交通、信息记录方式 |
| 经济 | 贸易形态、货币、税收、财富分配 |
| 医学 | 疾病认知、疗法、公共卫生 |
| 人文 | 宗教、艺术、教育、社会阶层观念 |
| 食物 | 主粮、烹饪、饮食结构与获取方式 |
| 历史 | 该文明对自身过去的叙述与记忆方式 |
| 地理 | 疆域、气候、地缘、迁徙 |
| 生产 | 农业/手工业/作坊组织与劳动分工 |
| 资源 | 矿产、水源、木材、能源利用 |

## 数据可信度分层

没有实际数据时，**不伪造精确数字**，而用四级标注：

| 级别 | 含义 | 页面表现 |
|------|------|----------|
| `documented` | 有文献或考古依据 | 实心标签「有据」 |
| `inferred` | 基于相邻证据的合理推断 | 虚线边框「推断」 |
| `speculative` | 猜测，待考证 | 斜纹背景「猜测」 |
| `absent` | 信息不足，不记录 | 留空或显示「—」 |

定性等级 `level`（1–5）仅在有依据或推断时使用，表示相对发达程度，**不是精确统计**。

## 页面布局（GitHub Pages）

```
┌─────────────────────────────────────────────────────────────┐
│  标题 · 当前年代：公元前 2500 年 · 青铜时代中期              │
├─────────────────────────────────────────────────────────────┤
│  ◀ ───────●────────────────────────────────────────── ▶    │  ← 时间轴滑块
│  -3000        -2000        -1000         0        1000      │
├─────────────────────────────────────────────────────────────┤
│  [古埃及] [两河流域] [古中国] [印度河]  …   ☐ 对比模式       │  ← 文明选择
├──────────────────────────┬──────────────────────────────────┤
│                          │  九维雷达图（定性 1–5）           │
│  文明概况卡片             │  虚线=推断  斜纹=猜测  空白=不记  │
│  · 疆域示意（文字）       ├──────────────────────────────────┤
│  · 时代标签               │  维度卡片网格（3×3）              │
│  · 与世界史对照一句       │  每格：摘要 + 可信度徽章          │
└──────────────────────────┴──────────────────────────────────┘
```

### 时间线推进逻辑

1. **滑块**连续选择年份（公元前为负值），页面在相邻**快照**之间插值或取最近快照。
2. 每个文明维护 `snapshots[]`，每条快照绑定 `year` 与九维 `dimensions`。
3. **对比模式**：并排显示 2 个文明的雷达图与卡片，便于同一年代横向比较。
4. 无快照的年份：显示「该时段暂无记录」，不强行填充。

### 技术选型（Pages 友好）

- 纯静态：`site/index.html` + `site/data/civilizations.json`
- 无构建步骤，GitHub Pages 从 `/site` 目录发布
- 雷达图用 Canvas 手绘，避免外部 CDN 依赖（可选）

原型地址：[site/](../../site/)（启用 Pages 后见 `https://<user>.github.io/Talk/`）

## 情景示例：公元前 2500 年

| 维度 | 古埃及（有据/推断） | 古中国·龙山晚期（多为推断） |
|------|---------------------|----------------------------|
| 科技 | 金字塔营造、青铜初期 | 黑陶、可能已有早期青铜 |
| 经济 | 尼罗河农业剩余、神庙经济 | 聚落农业、礼制萌芽 |
| 医学 | 草药与简单外科（推断） | 资料极少 → 不记录 |
| 食物 | 大麦、二粒小麦、啤酒 | 粟、黍为主粮 |
| 历史 | 王室年代记、神话与王权结合 | 口传为主，尚无系统史书 |
| 地理 | 尼罗河河谷、东西沙漠屏障 | 黄河流域台地、多元聚落 |
| 生产 | 国家组织的大型灌溉与劳役 | 村落农业与手工业分工 |
| 资源 | 尼罗河、石料、少量铜 | 黄土、黄河水、铜料来源待考 |

这种视图让人一眼看到：**不是「谁更先进」的单一排名**，而是**各文明在不同维度上的不同形状**。

```json

  "dimensions": [{ "id": "technology", "label": "科技" }],
  "civilizations": [{
    "id": "egypt",
    "name": "古埃及",
    "snapshots": [{
      "year": -2500,
      "eraLabel": "古王国晚期",
      "worldContext": "金字塔时代；两河流域城邦并存",
      "dimensions": {
        "technology": {
          "level": 4,
          "summary": "大型石构建筑、青铜工具、象形文字",
          "confidence": "documented"
        }
      }
    }]
  }]
}
```
