# 多维文明历史可视化

> **已孵化** — 实现与交互原型已迁移至独立仓库 [**CivSlice**](https://github.com/jk9988610/CivSlice)（文明切片）。  
> 本文档保留于 Talk 作为原始构想与方法论记录。

## 问题

观看国家历史讲解时，叙事线（王朝、战争、人物）难以同时把握文明在多个维度上的状态，更难以科学地区分「有据」「推断」与「猜测」。

## 十维框架（v2）

| # | 维度 | 说明 |
|---|------|------|
| 1 | 地理气候 | 空间、气候、地缘约束 |
| 2 | 资源能源 | 可开发的自然要素 |
| 3 | 技术能力 | 工具、方法、知识水平 |
| 4 | 生产组织 | 农业/手工业/劳动分工 |
| 5 | 经济交换 | 贸易、货币、分配 |
| 6 | 政治制度 | 国家形态、治理、官僚 |
| 7 | 军事国力 | 战争能力、疆域变动 |
| 8 | 社会文化 | 宗教、艺术、教育、阶层 |
| 9 | 日常生活 | 食物、医疗、居住（合并原食物+医学） |
| 10 | 历史记忆 | 自我叙述、史书、神话 |

跨域细节用 tags 补充（人口、法律、环境、外交等），不再单独占雷达轴。

> 完整数据规范见 [CivSlice 史料方法论与数据规范](2026-08-12-CivSlice-史料方法论与数据规范.md)；AI 工作指引见 [AI-GUIDE.md](../AI-GUIDE.md)。

## 科学方法原则

1. **考古与文献优先** — 推断须标注并说明逻辑链
2. **禁止以今证古** — 现代发展水平不能反推古代等级
3. **承认断裂** — 亡国、改朝、殖民、灾害造成的非连续性
4. **相对等级** — 1–5 为文明内部概括，非跨文明精确排名
5. **留空优于瞎填** — 无充分证据标记 `absent`

### 可信度分级

| 级别 | 含义 |
|------|------|
| `documented` | 考古实物或 contemporaneous 文献 |
| `inferred` | 基于相邻证据的合理推论 |
| `speculative` | 假说性判断，待检验 |
| `absent` | 证据不足，不做判断 |

## 倒推的边界

从现代截面倒推古代**仅适合生成假说**，须满足：

- 物质维度（地理、资源、部分技术）可信度高于文化维度
- 须先识别历史断裂点（如现代埃及 ≠ 古埃及）
- 倒推结果必须标注 `speculative` 或 `inferred`，不可标 `documented`
