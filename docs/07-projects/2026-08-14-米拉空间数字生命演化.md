# 米拉空间数字生命演化

> **已孵化** — 实现仓库：[**MiraSpace**](https://github.com/jk9988610/MiraSpace)（当前仅含占位 README，待按本文档体系实现）。  
> 本文档保留于 Talk 作为项目总览与世界观；**科学阶段划分**见 **[MiraSpace 科学阶段路线图](2026-08-14-MiraSpace-科学阶段路线图.md)**。

## 问题

如何在一个**可观察、可交互的数字空间**里，让具备达尔文演化能力的系统**涌现**出来——而不是用脚本预演「RNA、DNA、细胞」等名词里程碑？

地球生命史提供**参照系**，但工作计划须按**科学上的功能前提**排列，而非按教科书分子名称线性切分。详见 [科学阶段路线图 §为何不采用 RNA→DNA→细胞](2026-08-14-MiraSpace-科学阶段路线图.md#为何不采用rna--dna--细胞--多细胞作为工作计划)。

## 世界观：米拉空间

| 概念 | 定义 |
|------|------|
| **米拉空间** | 一种数字空间；画布上的一片（或多片）可模拟区域 |
| **居民** | 空间内的数字生物；形态与机制**模仿**地球生物的功能角色，但不复制真实化学 |
| **涌现** | 复制、边界、代谢耦合、协作等由微观规则与环境压强**自发**产生 |
| **环境** | 可调参数场（能量梯度、扩散、噪声、边界）；变化即选择压力 |
| **观察者** | 玩家不直接操控生物，只**观看与漫游**空间 |

### 核心原则（强制执行）

1. **涌现优先** — 禁止「到阶段就生成对应分子/细胞」；门槛须由指标判定。
2. **功能先于名称** — 实现复制子、膜、耦合单元，而非实现「RNA 类」「DNA 类」标签。
3. **环境驱动选择** — 适应度来自模拟交互，不是作者打分。
4. **观察者视角** — 默认仅**单指平移**画布（P0 起）；调试工具另议。
5. **留痕可审计** — 阶段跃迁可回放、可对照 seed、可导出指标。

## 阶段体系（科学版）

阶段分两层：**P0 工程基底** + **S1–S5 生物涌现**。完整科学问题、门槛与文献方向见 **[科学阶段路线图](2026-08-14-MiraSpace-科学阶段路线图.md)**。

```
P0  观察基底              Canvas · 坐标 · 观察者 · 模拟时钟
S1  远离平衡态与前生物复杂性    非平衡通量 · 自催化（无可遗传信息）
S2  达尔文阈值              可遗传变异 + 选择（复制子或代谢规则）
S3  个体化与原细胞            膜边界 · 内外 compartment · 分裂
S4  整合细胞单元             代谢–遗传–边界耦合（化学子）
S5  多细胞性                持久绑定 · 分工 · 发育式模式
```

| 编号 | 一句话目标 | 与旧「分子阶段论」的区别 |
|------|------------|--------------------------|
| P0 | 能稳定「看见」模拟 | 纯工程，非生物学 |
| S1 | 前生命复杂性 | 不是「还没有 RNA」，而是**还没有达尔文系统** |
| S2 | 跨代演化 | 地球常称 RNA 世界；我们实现**通用复制子**，不设 DNA 阶段 |
| S3 | 个体包被 | 膜在科学上常紧接或重叠复制子，非「DNA 之后」 |
| S4 | 自维持细胞单元 | DNA 式高保真存储若出现，是**本阶段涌现**，非独立阶段 |
| S5 | 多细胞协作 | 地球多次独立起源；模拟不预设动物/植物路径 |

> **当前聚焦**：[S4 化学子规格](2026-08-14-MiraSpace-S4-整合细胞单元.md) · [S3→S4 确认书](2026-08-14-MiraSpace-S3-S4-门槛确认书.md)

## 交互与呈现（跨阶段）

### 视口

- **主场景**：全屏 `<canvas>`，优先**手机 / 平板横屏**。
- **坐标系**：世界坐标（`mu`）与屏幕坐标分离；Y 轴向上为正。
- **观察者（P0 起）**：单指拖动平移；双指缩放等后续再议。

### 模拟节拍

- 固定逻辑 tick（如 30 Hz）与渲染帧率分离。
- 边界策略为环境参数；S1 默认**周期边界**便于观察 pattern。
