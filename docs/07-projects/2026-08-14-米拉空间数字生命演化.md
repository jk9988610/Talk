# 米拉空间数字生命演化

> **已孵化** — 实现仓库：[**MiraSpace**](https://github.com/jk9988610/MiraSpace)（当前仅含占位 README，待按本文档体系实现）。  
> 本文档保留于 Talk 作为项目总览、世界观与阶段路线图；具体阶段规格见子文档。

## 问题

如何在一个**可观察、可交互的数字空间**里，让「生命」从近似零的状态**涌现**出来——而不是用脚本预演 RNA、DNA、细胞等里程碑？

地球生命史提供了**参照系**（前化学 → RNA 世界 → DNA 信息存储 → 原核/真核细胞 → 多细胞），但米拉空间（Mira Space）中的居民是**数字生物**：它们的行为来自局部规则与环境压强下的**优胜劣汰**，不是设计者写好的演出。

## 世界观：米拉空间

| 概念 | 定义 |
|------|------|
| **米拉空间** | 一种数字空间；画布上的一片（或多片）可模拟区域 |
| **居民** | 空间内的数字生物；形态与机制**模仿**地球生物，但不复制真实化学 |
| **涌现** | 宏观模式（复制、代谢、膜、协作等）由微观交互**自发**产生 |
| **环境** | 可调参数场（能量梯度、扩散、噪声、边界条件）；变化即选择压力 |
| **观察者** | 玩家不直接操控生物，只**观看与漫游**空间 |

### 核心原则（强制执行）

1. **涌现优先** — 禁止用「阶段到了就生成一个 RNA 实体」的方式推进；里程碑须由模拟**判定**达成。
2. **模仿而非仿真** — 参照地球生命的**功能角色**（信息聚合物、复制误差、分隔、代谢），不必复刻真实分子动力学。
3. **环境驱动选择** — 适应度来自与环境的交互结果，不是作者打分。
4. **观察者视角** — 默认交互仅为**单指拖动平移画布**；不假设上帝模式编辑个体（后续阶段另议调试工具）。
5. **留痕可审计** — 关键跃迁须能回放或导出指标，便于验证「是否真的涌现」。

## 演化阶段路线图

整体目标：在米拉空间中，分阶段模拟从「无生命」到「多细胞生物」的递进。各阶段**解锁条件**由上一阶段的涌现指标触发，而非硬编码时间轴。

```
阶段 0  空域基底     画布 · 坐标系 · 观察者 · 原始汤底物（无复制者）
   ↓ 涌现：可持续的局部秩序 / 自催化网络
阶段 1  前生物化学   可变异的信息聚合物（RNA 类比）
   ↓ 涌现：稳定遗传 + 更高信息容量
阶段 2  DNA 类比     双链/冗余信息存储与修复
   ↓ 涌现：膜边界 + 内部化学 compartmentalization
阶段 3  细胞         膜包被的代谢单元（原核/真核类比）
   ↓ 涌现：细胞间信号与分工
阶段 4  多细胞       群体结构与发育式协作
```

| 阶段 | 名称 | 地球参照 | 米拉空间目标（涌现判定摘要） |
|------|------|----------|------------------------------|
| **0** | 空域与原始汤 | Hadean / prebiotic soup | 可交互画布 + 2D 场 + 粒子底物；出现**局部负熵岛**或自催化循环 |
| **1** | RNA 类比世界 | RNA world | 线型聚合物**模板复制** + 突变 + 选择；种群而非单个脚本实体 |
| **2** | DNA 类比链 | 遗传密码稳定化 | 更长的可修复信息链；复制保真度与容量可测量提升 |
| **3** | 细胞 | LUCA → 真核 | 膜封闭代谢；内外扩散差异；可分裂 |
| **4** | 多细胞 | 动物/植物起源 | 持久细胞间绑定 + 分工 + 发育式模式 |

> **当前聚焦**：阶段 0 的详细规格见 **[MiraSpace 阶段 0 — 空域、坐标与观察者](2026-08-14-MiraSpace-阶段0-空域坐标与观察者.md)**。

## 交互与呈现（跨阶段）

### 视口

- **主场景**：全屏 `<canvas>`（或 WebGL 等价层），优先适配**手机 / 平板横屏**。
- **坐标系**：世界坐标（模拟空间，单位 `mu`）与屏幕坐标分离；Y 轴向上为正（数学惯例），缩放与平移由视图矩阵统一管理。
- **观察者操作（阶段 0 起）**：
  - 单指拖动 → 平移画布（pan）
  - 双指 pinch / 双击等**不在阶段 0 范围**（可列入后续阶段）

### 模拟节拍

- 固定逻辑 tick（如 30 Hz）与可变渲染帧率分离。
- 模拟在「世界矩形」内运行；边界策略（周期 / 吸收 / 反射）为环境参数，阶段 0 默认**周期边界**以便观察 patterns。

## 技术方向（实现仓库）

预期 MiraSpace 结构（随阶段增量）：

```
MiraSpace/
├── site/                    # GitHub Pages 静态站点
│   ├── index.html
│   ├── styles.css
│   ├── js/
│   │   ├── main.js          # 入口、resize、orientation
│   │   ├── camera.js        # 视图矩阵、pan、坐标变换
│   │   ├── world.js         # 世界尺寸、tick、边界
│   │   ├── fields.js        # 标量/矢量场（阶段 0）
│   │   ├── particles.js     # 底物粒子（阶段 0）
│   │   └── metrics.js       # 涌现指标与阶段判定（后续）
│   └── data/
│       └── presets/         # 环境预设 JSON
├── .github/workflows/
│   └── pages.yml
└── README.md
```

**栈建议**：Vanilla JS + Canvas 2D 起步（与 CivSlice 一致，零构建、易 Pages）；粒子数或场分辨率成为瓶颈时再评估 WebGL / Worker。
