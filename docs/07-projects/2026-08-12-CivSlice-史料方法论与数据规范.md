# CivSlice 史料方法论与数据规范

> 本文档为 CivSlice 实现仓库的**数据与方法论权威来源**，由 Talk 仓库维护。  
> 实现代码见 [CivSlice](https://github.com/jk9988610/CivSlice)。

## 史料类型三分法

所有快照须标明主要证据来源类型：

| 类型 | 字段值 | 说明 | 可信度基线 |
|------|--------|------|-----------|
| 考古遗存 | `archaeology` | 遗址、器物、地层、测年 | 高（需解读） |
| 后世文献 | `literature` | 史书、铭文、档案 | 中（有时代距离） |
| 神话传说 | `mythology` | 口传、神话化叙事 | 低（政治叙事） |

### 信史起点

**公元前 841 年**（西周共和元年）为中国信史连续纪年起点。此前快照：

- `eraLabel` 优先用考古文化名（如「二里头文化」），而非争议王朝名（如「夏」）
- `historical_memory` 维度须注明「后世追述」

## 时代命名规范

| 时段 | `eraLabel` 规则 | 示例 |
|------|----------------|------|
| 前 841 年以前 | 考古文化分期 | 二里头文化、良渚文化 |
| 前 841 年—近代 | 王朝 + 时期 | 西周早期、北宋中期 |
| 近代—当代 | 政权 + 年份段 | 清嘉庆、共和国初期 |
| 有学术争议 | 考古名 + 注释 | 二里头文化（夏代争议） |

### 早期分期参考（中华文明探源工程）

```
古国时代（约前 5800—前 3800）
  ├── 第一阶段：牛河梁、凌家滩等
  ├── 第二阶段：良渚等
  └── 第三阶段：龙山、陶寺、石峁等
王朝时代：二里头等
```

## 可信度分级

| `confidence` | 含义 | UI 表现 |
|--------------|------|---------|
| `documented` | 考古实物或 contemporaneous 文献 | 绿色「有据」 |
| `inferred` | 相邻证据的合理推论 | 蓝色虚线「推断」 |
| `speculative` | 假说，待检验 | 黄色斜纹「猜测」 |
| `absent` | 证据不足 | 留空「未记录」 |

### 禁止

- 无考古/文献支撑标 `documented`
- 从现代状态反推古代标 `documented` 或高 `level`
- 用传说材料支撑 `technology`/`economy` 等高精度维度

## 倒推的边界

从现代截面倒推古代**仅适合生成假说**：

| 较可倒推 | 较难/不可倒推 |
|----------|--------------|
| 地理、资源禀赋 | 文化、信仰 |
| 部分技术前置树 | 医学、日常生活细节 |
| 制度遗产线索 | 因果链与偶然事件 |
| 语言/人群迁徙 | 已消亡文明的全貌 |

倒推结果必须标 `speculative` 或 `inferred`，且须先识别**历史断裂点**（如现代埃及 ≠ 古埃及）。

## 十维填充指南

| 维度 | 常见史料 | 维基百科覆盖度 | 补充来源建议 |
|------|----------|---------------|-------------|
| 地理气候 | 考古、方志、地质 | 中 | 历史地理专著 |
| 资源能源 | 考古、档案 | 低 | 经济史、环境史 |
| 技术能力 | 考古、文献 | 高 | 《中国科学技术史》 |
| 生产组织 | 文献、考古 | 中 | 农业史 |
| 经济交换 | 文献、出土货币 | 高 | 货币史 |
| 政治制度 | 文献、律令 | 高 | 制度史 |
| 军事国力 | 文献、兵器考古 | 高 | 军事史 |
| 社会文化 | 文献、艺术考古 | 中 | 思想史、宗教史 |
| 日常生活 | 考古、食谱文献 | 低 | 饮食史、医史 |
| 历史记忆 | 史书、铭文 | 中（混在叙事中） | 史学史 |

**原则**：维基偏政治军事叙事；医学、日常、资源须主动补源或标 `absent`。

## 快照 JSON Schema

```json
{
  "year": -500,
  "eraLabel": "春秋末期",
  "evidenceTypes": ["archaeology", "literature"],
  "evidenceNote": "一句说明本条快照的主要证据链",
  "worldContext": "同期世界背景，一句",
  "sources": [
    {
      "type": "literature",
      "ref": "《左传》",
      "note": "可选： contemporaneous 编年史"
    },
    {
      "type": "archaeology",
      "ref": "曾侯乙墓考古报告"
    }
  ],
  "controversies": [
    "可选：学术争议，如战国起点有不同划分"
  ],
  "rejectedHypotheses": [
    {
      "claim": "可选：已反驳假说",
      "refutedBy": "反驳依据",
      "confidence": "documented"
    }
  ],
  "dimensions": {
    "<dimension_id>": {
      "level": 4,
      "summary": "一句定性概括",
      "confidence": "documented",
      "note": "可选：如「后世史书有立场偏差」"
    }
  }
}
```

### `level` 规则

- 整数 1–5，表示该文明**内部**相对程度
- 无充分依据时不填（`null`），`confidence` 标 `absent`
- 不可用于跨文明排名（「北宋 technology 5 > 同时期欧洲 3」）

### `historical_memory` 维度特殊规则

记录**该文明如何叙述自己的过去**，而非「过去实际怎样」：

```json
"historical_memory": {
  "level": 4,
  "summary": "《春秋》编年体史书，史官传统",
  "confidence": "documented",
  "note": "记录的是当时人的历史意识，不等于信史"
}
```

## 已反驳假说记录

科学探索须记录「不是什么」，示例：

| 假说 | 反驳依据 | 相关时段 |
|------|----------|----------|
| 中国文明整体源自古巴比伦 | 仰韶—龙山—二里头本土连续序列 | 史前 |
| 仰韶彩陶技术自中亚传入 | 后岗地层叠压证明本土发展 | 新石器 |
| 二里头 = 整个夏朝 | 学界多认为不能简单等同 | 夏商之际 |

写入快照的 `rejectedHypotheses` 或国家级的 `meta.rejectedHypotheses`。

## 从维基百科提取的工作流

```
1. 定位时段 → 找到维基对应章节
2. 识别史料类型 → 填入 evidenceTypes
3. 拆入十维 → 每维独立写 summary + confidence
4. 标记争议 → 写入 controversies
5. 分离历史记忆 → 后世叙述偏差写入 historical_memory.note
6. 补缺口维度 → 维基没有的查专题史或标 absent
7. 结构化引用 → 写入 sources，附 type 与 note
```

维基是素材库，不是权威数据源。提取内容须交叉验证。
