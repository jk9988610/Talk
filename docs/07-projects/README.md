# 项目构想

存放产品创意、开源项目设想、实验性 side project 与可行性分析。

## 适合放入此处

- 产品需求与目标用户描述
- 技术方案草图与架构草案
- MVP 范围与里程碑规划
- 放弃或暂停项目的复盘

## 建议结构

1. **问题** — 要解决什么？
2. **方案** — 打算怎么做？
3. **差异化** — 与现有方案有何不同？
4. **风险** — 技术、市场、资源上的主要障碍
5. **下一步** — 验证假设的最小行动
