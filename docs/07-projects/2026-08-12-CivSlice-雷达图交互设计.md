# CivSlice 雷达图交互设计

> 实现仓库：[CivSlice](https://github.com/jk9988610/CivSlice)  
> 关联：[项目总览](2026-08-12-多维文明历史可视化.md) · [数据规范](2026-08-12-CivSlice-史料方法论与数据规范.md)

## 设计目标

1. **雷达图纯视觉化** — 文字说明全部沉入维度卡片，雷达区只保留图形
2. **节省纵向空间** — 移动端友好，减少重复信息
3. **支持对比** — 文明互比 + 时代平均背景板，两种模式可切换

---

## 布局：雷达精简 + 卡片承载文本

### 原则

| 区域 | 放什么 | 不放什么 |
|------|--------|----------|
| 雷达图 | 网格、轴标签（2 字简称）、多边形、顶点色点 | 摘要文字、可信度徽章、等级数字 |
| 维度卡片 | 维度全名、等级、可信度徽章、摘要、note | 无 |

### 桌面布局

```
┌─────────────────────────────────────────────────────┐
│  时间轴 + 文明选择 + 对比模式切换                      │
├──────────────┬──────────────────────────────────────┤
│              │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐  │
│   雷达图      │  │地理│ │资源│ │技术│ │生产│ │经济│  │
│   (纯图形)    │  └────┘ └────┘ └────┘ └────┘ └────┘  │
│   ~280×280   │  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐  │
│              │  │政治│ │军事│ │文化│ │日常│ │记忆│  │
│  图例（极简）  │  └────┘ └────┘ └────┘ └────┘ └────┘  │
│  ●有据 ○推断  │  ← 5×2 网格，与雷达轴一一对应          │
├──────────────┴──────────────────────────────────────┤
│  侧栏：快照信息 / 证据说明 / 对比图例                  │
└─────────────────────────────────────────────────────┘
```

### 移动端

雷达缩小至 ~220px 宽，卡片改为单列，雷达在上、卡片在下滚动。

### 卡片与雷达联动

- 悬停卡片 → 对应雷达轴高亮
- 悬停雷达轴 → 对应卡片边框高亮
- 点击卡片 → 展开完整摘要（若默认折叠）

### 卡片紧凑模式（默认）

```
┌─────────────────┐
│ 技术能力    [有据] │
│ ████░  4/5        │  ← 可选细进度条
│ 铁器推广、青铜礼器… │  ← 一行截断，点击展开
└─────────────────┘
```

`confidence: absent` 的卡片灰显，雷达对应轴无顶点。

## 对比模式

提供三种雷达对比模式，通过顶部切换器选择：

| 模式 | 标识 | 说明 |
|------|------|------|
| **单文明** | `solo` | 仅显示选中文明，默认模式 |
| **文明互比** | `compare` | 2–3 个文明多边形叠图 |
| **时代均值** | `vs-average` | 选中文明 + 同期文明平均背景板 |

### 模式一：单文明（solo）

- 一条实心多边形，文明主题色
- 顶点颜色 = 可信度（绿/蓝/黄）
- 无背景板

### 模式二：文明互比（compare）

```
        科技
         ▲
    ╱‾‾‾‾╲
   ╱ 红   ╲      ← 中国（实心）
  │ ╱蓝╲  │
   ╲    ╱       ← 埃及（半透明描边）
    ╲__╱
```

规则：

- 最多同时叠 **3** 个文明（可读性上限）
- 第 1 个：实心填充 20% 透明度 + 实线描边
- 第 2、3 个：仅描边（虚线），无填充
- 图例列于雷达下方：色块 + 文明名 + 时代标签
- **维度卡片**：切换为对比表格或分栏（每文明一列摘要）

文明选择区支持多选（checkbox 或 toggle），超过 3 个时提示「最多选 3 个」。

### 模式三：时代均值背景板（vs-average）

```
        科技
         ▲
    ╱‾‾‾‾╲
   ╱ 灰色  ╲     ← 同期文明均值（虚线、15% 填充）
  │ ╱红 ╲  │    ← 选中文明（实心）
   ╲    ╱
    ╲__╱
```

**均值计算规则**：

```javascript
// 伪代码
function periodAverage(year, dimensionId, civilizations, tolerance) {
  const snaps = civilizations
    .map(civ => nearestSnapshot(civ, year))
    .filter(s => s && Math.abs(s.year - year) <= tolerance)
    .map(s => s.dimensions[dimensionId])
    .filter(d => d && d.confidence !== 'absent' && d.level != null);

  if (snaps.length < 2) return null; // 不足 2 个文明不显示均值
  return snaps.reduce((sum, d) => sum + d.level, 0) / snaps.length;
}
```

显示规则：

- 均值多边形：**灰色虚线**描边 + 浅灰 15% 填充
- 选中文明：主题色实心
- 雷达下方标注：`同期均值（n=4 文明）`
- 某维度参与均值计算的文明数 < 2 → 该轴不画均值点

**与互比模式的关系**：`vs-average` 可与 `solo` 叠加（单文明 + 背景），不与 `compare` 同时启用（避免超过 4 条多边形混乱）。

推荐默认：**单文明 + 可选开启「显示时代均值」开关**（checkbox），而非独立第三种模式——降低 UI 复杂度。

## 推荐 UI 控件（简化方案）

```
[ 中国 ▼ ]  [ 埃及 ]  [ 两河 ]  ...     ☑ 显示同期均值    ☐ 对比模式
```

| 控件 | 行为 |
|------|------|
| 文明单选（默认） | solo 模式 |
| 「对比模式」勾选 | 文明选择变多选，最多 3 个 |
| 「显示同期均值」 | 在 solo 或 compare 下叠加灰色均值背景 |

两个 checkbox 互斥逻辑：

- 开启对比模式 → 自动关闭「同期均值」（或均值基于所选 3 文明的均值，非全局）
- 仅单选时 → 「同期均值」= 该年所有有快照文明的均值

## 雷达绘制规范

### 尺寸

| 断点 | 画布 |
|------|------|
| 桌面 | 280×280 |
| 平板 | 240×240 |
| 手机 | 220×220 |

### 图层顺序（底 → 顶）

1. 网格环（5 环，#2e3344）
2. 轴线 + 轴标签（10 字简称）
3. **均值背景多边形**（若有，灰色虚线）
4. **对比文明多边形**（若有，描边优先）
5. **主文明多边形**（实心）
6. 顶点可信度色点

### 轴标签

仅用 `dimensions[].short`（2 字），完整名称在卡片标题显示。

## 维度卡片在对比模式下的变化

### solo / vs-average

保持 5×2 网格，每卡显示选中文明的单条摘要。

### compare（2–3 文明）

卡片改为**按维度一行对比**：

```
┌─ 技术能力 ─────────────────────────────────┐
│ 中国 4/5 [有据]  铁器推广、青铜礼器…        │
│ 埃及 4/5 [有据]  金字塔营造、青铜工具…      │
└──────────────────────────────────────────┘
```

或横向三列（桌面）/ 纵向堆叠（移动）。

## 空间节省估算

| 改动 | 节省 |
|------|------|
| 雷达区移除 legend 长文本 → 卡片徽章 | ~60px 高 |
| 卡片摘要默认一行截断 | ~40% 卡片高度 |
| 侧栏证据说明改为可折叠 `<details>` | ~120px |
| 雷达与卡片并排（非上下） | ~200px 纵向 |

## 开放问题

1. 均值是否加权？（按人口、疆域还是简单算术平均）→ 建议先简单算术，标注「非加权」
2. 对比模式下可信度色点是否保留？→ 建议仅主文明保留色点，对比文明只用描边色
3. 单国阶段（仅中国）时「同期均值」是否隐藏？→ 是，`n < 2` 时不显示
