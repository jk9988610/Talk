# CivSlice 时间轴交互流程

> 实现仓库：[CivSlice](https://github.com/jk9988610/CivSlice)  
> 关联：[时代维度模板](2026-08-12-CivSlice-时代维度模板.md) · [雷达图交互设计](2026-08-12-CivSlice-雷达图交互设计.md)

## 核心交互

> **先选时间段 → 再加载该时段内的朝代/国家 → 最后在段内拖动时间轴。**

避免用户从公元前 3000 一路滑到 2024，维度集、可选文明、快照密度完全不同，一次全轴滑动体验差且易误读。

## 三级导航

```
┌─ ① 时代段（Era Period）────────────────────────────┐
│  [石器] [新石器] [青铜] [铁器帝国] [近代早期] [工业] [当代] │
└────────────────────────────────────────────────────┘
              ↓ 选定后收窄范围 + 切换 eraTemplate
┌─ ② 文明 / 朝代（Civilization / Dynasty）──────────┐
│  仅显示在该时代段有快照的实体                          │
│  中国模式：西周 | 春秋战国 | 秦汉 | 唐宋 | 清 | …      │
│  多国模式：中国 | 埃及 | 罗马 | …（同时代有数据的）     │
└────────────────────────────────────────────────────┘
              ↓ 选定默认实体，可切换对比
┌─ ③ 时间轴（Timeline，段内滑动）─────────────────────┐
│  ◀ ────────●────────────────── ▶                   │
│  范围 = 当前时代段的 yearMin ~ yearMax               │
│  圆点 = 该实体在本段内的快照                          │
└────────────────────────────────────────────────────┘
              ↓
         剖面 / 对比雷达 + 卡片
```

## ① 时代段选择

与 [时代维度模板](2026-08-12-CivSlice-时代维度模板.md) 的 `eraTemplate` 一一对应：

| eraTemplate | 显示名 | 默认年份范围 |
|-------------|--------|-------------|
| `paleolithic` | 石器时代 | −∞ ~ −10000 |
| `neolithic` | 新石器 | −10000 ~ −4000 |
| `bronze` | 青铜时代 | −4000 ~ −1000 |
| `iron_imperial` | 铁器与帝国 | −1000 ~ 1500 |
| `early_modern` | 近代早期 | 1500 ~ 1800 |
| `industrial` | 工业时代 | 1800 ~ 1945 |
| `contemporary` | 当代 | 1945 ~ 今 |

### 行为

- 点击时代段 → 重置②③级选择
- 时间轴 `min`/`max` 设为该段 `yearRange`
- 剖面雷达切换为该段 `eraTemplate` 的维度集
- 顶部显示：`青铜时代 · 公元前 4000 — 公元前 1000`

### 数据

```json
{
  "meta": {
    "eraPeriods": [
      {
        "id": "bronze",
        "label": "青铜时代",
        "yearMin": -4000,
        "yearMax": -1000,
        "eraTemplate": "bronze"
      }
    ]
  }
}
```

## ② 文明 / 朝代加载

选定时代段后，**动态过滤**有快照落在该段内的实体。

### 过滤规则

```javascript
function civilizationsInPeriod(civilizations, period) {
  return civilizations.filter(civ =>
    civ.snapshots.some(s =>
      s.year >= period.yearMin && s.year <= period.yearMax
    )
  );
}
```

### 中国单国模式

`country: "中国"` 时，②级显示**朝代/分期**而非多国：

| 时代段 | ②级选项（示例） |
|--------|----------------|
| bronze | 二里头、商、西周早期 |
| iron_imperial | 春秋、秦、东汉、北宋、明 |
| contemporary | 清晚期、民国、共和国初期 |

实现：快照增加可选字段 `dynasty` 或复用 `eraLabel` 分组：

```json
{
  "year": -500,
  "eraLabel": "春秋末期",
  "dynasty": "东周",
  "group": "春秋战国"
}
```

②级 UI 按 `group` 或 `dynasty` 聚合成 Tab/Chips。

### 多国模式

②级为国家列表，仅含该时段有数据的文明（如 bronze 段：中国、埃及、两河、印度河）。

### 默认选中

- 进入时代段后，默认选中②级**第一个**实体（或上次记忆）
- 时间轴跳到该实体在本段内**最接近段中点**的快照年份

---

## ③ 段内时间轴

### 范围

- 滑块范围 = 当前时代段 `yearMin` ~ `yearMax`，**不跨段**
- 步进：段长 > 2000 年用 50 年；< 500 年用 10 年；当代用 5 年

### 快照圆点

- 仅显示**当前选中实体**（及对比模式下其他实体）在本段内的快照
- 点击圆点 → 滑块跳转该年

### 切换时代段时

1. 保存用户上次各段选择（localStorage 可选）
2. 若新段内当前实体无快照 → 自动切到②级第一项
3. 若②级为空 → 显示「该时段暂无记录，欢迎贡献数据」

## ②½ 各国泳道时间轴（阶段内总览）

> **选中时代段并加载国家后，展示该阶段内各国的平行时间轴。**  
> 方法论定位：**分期—共时—分层比较**的可视化（见 [08-discussions 协作方法论](../08-discussions/2026-08-12-文档驱动构想结对协作.md)）。

### 位置

介于②级（国家/朝代选择）与③级（主时间轴）之间，作为**导航地图**：

```
① 时代段
    ↓
② 国家 Chips
    ↓
②½ 各国泳道时间轴  ← 本节
    ↓
③ 主时间轴 + 雷达（显微镜）
```

### 展示形态

#### A. 泳道 + 快照点（默认，P1）

横轴 = 当前时代段 `yearMin` ~ `yearMax`，每国一行，圆点 = 该国在本段内的快照：

```
埃及  ○───○───────○
中国  ────○───○───────○
罗马  ──────────○───○
      |    |    |    |
    -1000 -500   0  500
```

#### B. 存在条（可选，P4）

若有 `presence` 元数据，在泳道画色带表示活跃期，圆点仍标快照：

```
埃及  [═══════════════]  ○──○──○
中国  [═════════════════════]  ○─○─○
```

#### C. 中国单国 → 朝代多泳道（P3）

选中国且段内有多 `group` 时，展开为朝代分行：

```
东周   ──○────────○
秦     ────○
汉     ────────○────○
北宋   ──────────────○
```

### 交互

| 操作 | 行为 |
|------|------|
| 点击泳道圆点 | 选中该国 → ③主时间轴跳至该年 → 更新雷达 |
| 点击泳道行（非点） | 仅选中该国 → ③跳到该段内最近快照 |
| 对比模式 | 高亮多条泳道，③叠图对比 |
| 悬停圆点 | 显示 `eraLabel` + 年份 |

### 计算逻辑

```javascript
function timelinesInPeriod(civilizations, period) {
  return civilizations
    .map(civ => {
      const markers = civ.snapshots.filter(
        s => s.year >= period.yearMin && s.year <= period.yearMax
      );
      return {
        id: civ.id,
        name: civ.name,
        color: civ.color,
        markers,
        span: markers.length ? {
          start: Math.min(...markers.map(m => m.year)),
          end: Math.max(...markers.map(m => m.year)),
        } : null,
        presence: civ.presence?.find(p =>
          overlaps(p, period.yearMin, period.yearMax)
        ) ?? null,
      };
    })
    .filter(t => t.markers.length > 0 || t.presence);
}

function timelinesByDynasty(civ, period) {
  const markers = civ.snapshots.filter(s => inPeriod(s, period));
  const groups = new Map();
  for (const m of markers) {
    const key = m.group || m.dynasty || m.eraLabel;
    if (!groups.has(key)) groups.set(key, []);
    groups.get(key).push(m);
  }
  return [...groups.entries()].map(([label, ms]) => ({
    label, markers: ms, id: `${civ.id}:${label}`,
  }));
}
```

### 空数据

- 某国在本段仅 1 个快照 → 仍显示一行单点
- 段内仅 1 国 → 泳道区可折叠，或仍显示便于未来扩展
- 无国有条目 → 不渲染泳道区，提示贡献数据

### 与主时间轴关系

| 组件 | 角色 |
|------|------|
| ②½ 泳道总览 | 共时地图：谁在场、何时有记录 |
| ③ 主时间轴 | 单国精细滑动 + 驱动雷达 |
| 点击联动 | 泳道选点 = ③定位 + 雷达刷新 |

## 完整用户路径示例

```
1. 用户点击 [铁器与帝国]
   → 时间轴变为 −1000 ~ 1500
   → ②级出现：春秋战国 | 秦 | 东汉 | 北宋 | …

2. 用户点击 [北宋]
   → 时间轴圆点标出 1000 等
   → 滑块默认跳到 1000
   → 加载北宋快照 + iron_imperial 维度集

3. 用户拖动滑块到 1100
   → 仍取最近快照（1000）或显示「该年无快照」

4. 用户开启对比 + 选 [埃及]
   → 若埃及在 iron_imperial 段有快照，叠图对比
   → 若无，②级埃及灰显或不可选
```

## 与双雷达的关系

| 步骤 | 剖面雷达 | 对比雷达 |
|------|----------|----------|
| 选时代段 | 切换维度集（eraTemplate） | 派生指标用该段权重表 |
| 选朝代/国家 | 加载对应 snapshots | 可选多实体叠图 |
| 拖时间轴 | 取最近快照更新十维 | 重算派生指标 |

## 数据模型补充

```json
{
  "snapshots": [{
    "year": 1000,
    "eraLabel": "北宋中期",
    "eraTemplate": "iron_imperial",
    "dynasty": "宋",
    "group": "北宋",
    "periodId": "iron_imperial"
  }]
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `eraTemplate` | 推荐 | 维度集，可由 year 推断 |
| `dynasty` | 可选 | 朝代名，用于②级分组 |
| `group` | 可选 | ②级 Chip / 泳道分行（如「春秋战国」「北宋」） |

可选文明级字段：

```json
{
  "id": "egypt",
  "name": "古埃及",
  "presence": [
    { "start": -3100, "end": -30, "label": "法老时代" }
  ]
}
```

| `presence` | 可选 | 文明活跃期，用于泳道存在条（B 形态） |

`periodId` 可与 `eraTemplate` 相同，或更粗（如「中国古代」包多个 template）。

## 实现优先级

| 阶段 | 内容 |
|------|------|
| P1 | 时代段 Tab + 过滤 yearRange + 重置时间轴 |
| P2 | ②级朝代/国家 Chips（按段过滤） |
| P3 | 段内快照圆点 + 默认跳转 |
| P4 | **②½ 各国泳道时间轴** + 点击联动主时间轴 |
| P5 | 中国朝代多泳道（group 分行） |
| P6 | presence 存在条、对比高亮、localStorage |

---

## 禁止事项

- 未选时代段即展示全历史时间轴（−3000 ~ 2024）
- 时代段与 `eraTemplate` 不一致却不提示
- ②级显示该段无快照的实体（可灰显但不可选）
- 跨段拖动时间轴
