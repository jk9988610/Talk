# MiraSpace 阶段 0 — 空域、坐标与观察者

> **文档编号「阶段 0」= 实现里程碑**；对应科学路线图中的 **P0（观察基底）** + **S1（远离平衡态与前生物复杂性）起步**。  
> **父文档**：[米拉空间数字生命演化](2026-08-14-米拉空间数字生命演化.md) · [科学阶段路线图](2026-08-14-MiraSpace-科学阶段路线图.md)

## 本阶段要做什么（一句话）

完成 **P0 观测基础设施**（Canvas、坐标、单指 pan、模拟时钟），并搭建 **S1 前生物底物**（场 + 粒子、无模板复制）；用指标监测是否出现值得进入 **S2 达尔文阈值** 的底物复杂性——**不**在本里程碑实现可遗传复制子。

## 目标与非目标

### 目标（Must）

| # | 目标 | 验收要点 |
|---|------|----------|
| G1 | **画布空域** | 全屏 canvas；横屏布局可用；竖屏显示友好提示 |
| G2 | **坐标系** | 世界坐标 ↔ 屏幕坐标可逆变换；网格或标尺可选显示 |
| G3 | **观察者平移** | 单指 touch / mouse drag 平移视图；无默认缩放 |
| G4 | **模拟世界** | 固定 tick 更新；周期边界；可暂停/继续 |
| G5 | **原始汤底物** | 多种粒子 + 至少一种扩散/降解场；随机初始化 |
| G6 | **S1 涌现指标** | 实时计算并显示 2–3 个标量（见 §六）；供 S2 开发决策引用 |
| G7 | **可部署** | MiraSpace `site/` 通过 GitHub Pages 可访问 |

### 非目标（Must Not — 本里程碑）

- 不实现可遗传复制子、膜个体、整合细胞或多细胞体
- 不实现 RNA/DNA 命名实体或「里程碑解锁动画」
- 不用脚本生成「假装涌现」的图案
- 不做双指缩放、旋转、个体选取（留给后续）
- 不做存档/分享（可留接口）
- 不做真实化学方程或量子模拟

## 空间与坐标系

### 世界

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `worldWidth` | `4096` | 世界宽（`mu`，米拉单位） |
| `worldHeight` | `2048` | 世界高；横屏下宽 > 高 |
| `boundary` | `wrap` | 周期边界：粒子与场左右/上下环绕 |
| `origin` | 世界中心 | 初始相机对准 `(worldWidth/2, worldHeight/2)` |

### 坐标约定

```
屏幕坐标 (px)：原点左上，x 右增，y 下增
世界坐标 (mu)：原点左下，x 右增，y 上增   ← 模拟与物理使用
```

变换链：

```
screen = viewMatrix * world
world  = inverse(viewMatrix) * screen
```

`viewMatrix` 在阶段 0 仅含 **平移** ` (camX, camY) `，缩放 `zoom = 1` 固定（1 mu = 1 px 在参考布局下，resize 时按 CSS 像素比调整）。

### 相机（观察者）

| 状态 | 字段 | 说明 |
|------|------|------|
| 位置 | `camX`, `camY` | 世界坐标下视口中心 |
| 视口 | `viewportW`, `viewportH` | CSS 像素，随 resize/orientation 更新 |

**约束**：相机不跟随任何实体；纯观察者漫游。

## 交互规格

### 单指平移（P0）

| 输入 | 行为 |
|------|------|
| `pointerdown` | 记录起点 `(sx0, sy0)` 与 `(camX0, camY0)` |
| `pointermove`（按下） | `camX = camX0 - (sx - sx0) / zoom`；Y 轴注意屏幕/世界翻转 |
| `pointerup` / `cancel` | 结束拖动 |

- 使用 Pointer Events，统一 touch / mouse。
- 拖动时临时禁用浏览器默认滚动（`touch-action: none`）。
- **仅一根指针**响应；第二根指针忽略。

### 横屏适配（P0）

- 监听 `orientationchange` 与 `resize`。
- 目标：`innerWidth > innerHeight` 时进入主模拟；否则 overlay 提示「请旋转至横屏」。
- 安全区：`env(safe-area-inset-*)` 留白，避免刘海遮挡 HUD。

### HUD（P1）

最小只读信息（屏幕固定，不随 pan 移动）：

- 当前 tick / 模拟时间
- 暂停按钮
- 涌现指标只读数值（§六）
- 可选：切换网格、场热力图 opacity

## 模拟架构

### 时钟

```
renderLoop (requestAnimationFrame, 可变 FPS)
    └── 仅绘制最新状态

simLoop (固定 Δt)
    └── 每 frame 累积 realTime，while (acc >= DT) { tick(); acc -= DT; }
```

| 常量 | 建议值 |
|------|--------|
| `DT` | `1/30` 模拟秒/tick |
| `maxSubsteps` | `4`（防止卡顿螺旋） |

### 场（Fields）

阶段 0 至少 **2 个标量场**，分辨率 `256 × 128`（可配置），双线性插值采样：

| 场 id | 含义 | 更新概要 |
|-------|------|----------|
| `energy` | 可用化学势 / 光能代理 | 缓慢 replenishment + 扩散 + 被粒子消耗 |
| `waste` | 代谢废物 / 抑制 | 粒子排放 + 扩散 + 线性降解 |

扩散方程（离散 Laplacian）：

```
field += DT * (D * laplacian(field) + source - sink)
```

边界与粒子一致（wrap）。

### 粒子（原始汤底物）

| 类型 id | 颜色建议 | 行为摘要 |
|---------|----------|----------|
| `monomer` | 浅蓝 | 布朗运动 + 弱向 `energy` 梯度偏置；吸收 energy 维持活性 |
| `catalyst` | 琥珀 | 低 mobility；催化邻近 monomer 成对结合（可逆） |
| `dimer` | 深蓝 | 由 two monomers 结合；可解离；略高 energy 消耗 |

**禁止**：dimer 或任何结构**不得**携带可模板复制的序列信息（那是 **S2 达尔文阈值** 才开放的机制）。

粒子数据结构（示意）：

```js
{
  id, type,
  x, y, vx, vy,
  energy,  // 个体代谢池
  age      // tick 计数
}
```

数量级：初始 `N ≈ 800`（可调 preset），上限 `N_max = 4000` 防止性能崩溃。

### 渲染层

| 层 | 内容 |
|----|------|
| L0 | 背景 + 可选网格 |
| L1 | `energy` 场热力图（半透明） |
| L2 | 粒子（按 type 分色） |
| L3 | HUD |

仅绘制视口 AABB 与 wrap 邻域内的粒子（裁剪）。

## S1 涌现指标（本里程碑 → S2 决策）

本里程碑**不宣布「生命诞生」**（NASA 定义要求达尔文演化，属 **S2**）。只量化前生物底物是否具备足够**远离平衡态复杂性**，以 justify 开发 S2 复制子模块。

| 指标 id | 名称 | 计算概要 | 科学路线图对应 | S2 启动建议（待定） |
|---------|------|----------|----------------|---------------------|
| `clusterIndex` | 空间聚簇 | dimer 最近邻：局部密度 / 全局密度 | S1 空间结构 | 持续 > 1.8 达 60 s |
| `autocatalyticScore` | 自催化 | catalyst 邻近 dimer 生成率 / 全局平均 | S1 自催化 | 持续 > 1.2 达 60 s |
| `negentropyFlux` | 负熵流 | 类型分布 unevenness 相对初始的变化率 | S1 远离平衡态 | 60 s 滑动平均 > 基线 ×1.3 |

**实现要求**：

- 指标每 tick 或每 10 tick 更新，HUD 显示当前值 + 60 s 滑动平均。
- 写入 `metrics.js`；**门槛常量**放 `data/presets/stage0-default.json`，便于 Talk 改文档后 MiraSpace 改 JSON。

本里程碑完成时：**S1 指标可测量、可绘制曲线（P2）**；是否达 S2 启动阈**不阻塞** PR，但须在 README 记录示例运行截图或数值。

## MiraSpace 实现任务分解

### P0 — 观察基底（必须先合）

1. `index.html` + 全屏 canvas + 横屏提示 overlay
2. `camera.js`：世界 ↔ 屏幕、单指 pan
3. `world.js`：固定 tick 循环、暂停
4. 网格背景 + 视口裁剪绘制

**P0 完成定义**：空白世界上可流畅拖动；tick 计数增加；Pages 可访问。

### P1 — S1 前生物底物

5. `fields.js`：energy / waste 扩散与渲染热力图
6. `particles.js`：三类粒子 + wrap + 基础代谢
7. `metrics.js`：三项指标 + HUD
8. `data/presets/stage0-default.json` 加载

**P1 完成定义**：可见粒子场互动；HUD 指标跳动；无 JS 错误。

### P2 —  polish

9. 60 s 指标 sparkline 或迷你曲线
10. URL `?seed=` 复现
11. 性能：场更新可降采样；粒子 culling
