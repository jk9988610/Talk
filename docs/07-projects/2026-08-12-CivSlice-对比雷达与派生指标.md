# CivSlice 对比雷达与派生指标

> 实现仓库：[CivSlice](https://github.com/jk9988610/CivSlice)  
> 关联：[雷达图交互设计](2026-08-12-CivSlice-雷达图交互设计.md) · [数据规范](2026-08-12-CivSlice-史料方法论与数据规范.md)

## 核心结论

CivSlice 采用**双雷达架构**：

| 视图 | 轴 | 用途 | 数据来源 |
|------|-----|------|----------|
| **剖面** | 原始十维 | 科学探索、史料记录 | `snapshots[].dimensions` |
| **对比** | 6–8 项派生指标 | 跨文明球员卡式比较 | **运行时计算**，不写入 JSON |

> **十维是史料层；对比指标是展示衍生品。**  
> 禁止用派生分替代或覆盖十维原始 `level` / `confidence`。

---

## 为什么需要两套雷达

原始十维不适合直接做跨文明对比：

| 问题 | 球员卡（FIFA） |
|------|----------------|
| 维度常 `absent` | 每项必有分 |
| `level` 为文明内部相对值 | 全球统一 0–100 |
| 跨文明「军事 4」标准不一 | 「速度 85」定义一致 |
| 可信度参差 | 不混入展示轴 |

对比雷达的轴必须是**事先设计、刻度统一、专为跨文明比较**的派生值。

---

## 方法论原则

### 1. 分数与可信度分离，禁止相乘存储

- `level`：我们认为该维有多发达（文明内部 1–5）
- `confidence`：我们有多把握（`documented` / `inferred` / `speculative` / `absent`）
- **禁止**在 JSON 中存储 `level × confidence系数` 作为权威数据
- 计算派生指标时，可对 `speculative` **降权**（见公式），但须保留原始十维

### 2. 无知 ≠ 落后

- `absent` 不参与该项派生指标计算
- 算不出时标 `null`，UI 显示「N/A」或该轴缺角
- **禁止**将 `absent` 当作 0 分

### 3. 派生指标可复现

- 公式写在 `site/js/stats.js`（或同等模块），与文档一致
- UI 可展开「本项由 技术(4)×0.6 + 文化(3)×0.4 得出」

## 七项派生指标（对比雷达轴）

刻度统一 **0–100**。命名简短，适合雷达轴标签。

| id | 中文 | 英文标签 | 含义 |
|----|------|----------|------|
| `mobilization` | 动员力 | MOB | 集中资源、战争与大型工程能力 |
| `innovation` | 创新力 | INN | 技术突破与知识积累 |
| `prosperity` | 繁荣度 | PRO | 贸易、财富与生产效率 |
| `stability` | 制度稳 | STA | 治理连续性与国家组织 |
| `livelihood` | 民生力 | LIV | 日常生存、医疗与资源获取 |
| `influence` | 影响力 | INF | 地缘辐射与对外扩张 |
| `evidence` | 记录度 | EVI | 元指标：十维证据充分程度 |

`heritage`（传承度）可选为第 8 项，首版可先上 7 项（含 `evidence`）。

### 十维 → 派生指标权重表

| 派生指标 | 权重来源（十维 id） |
|----------|---------------------|
| mobilization | politics 0.35, military 0.40, production 0.25 |
| innovation | technology 0.65, culture 0.35 |
| prosperity | economy 0.55, production 0.45 |
| stability | politics 0.50, historical_memory 0.50 |
| livelihood | daily_life 0.55, resources 0.45 |
| influence | military 0.35, geography 0.30, economy 0.35 |
| evidence | 十维等权（见下） |

## 计算公式

### 单项派生指标（0–100）

```javascript
/**
 * @param {object} snapshot - 含 dimensions 的快照
 * @param {object} weights - { dimensionId: weight } 权重和应为 1
 * @returns {number|null} 0-100 或 null（数据不足）
 */
function computeStat(snapshot, weights) {
  let sum = 0;
  let weightSum = 0;

  for (const [dimId, wgt] of Object.entries(weights)) {
    const d = snapshot.dimensions?.[dimId];
    if (!d || d.confidence === 'absent' || d.level == null) continue;

    const confMul = d.confidence === 'speculative' ? 0.5
                  : d.confidence === 'inferred' ? 0.85
                  : 1.0; // documented

    sum += d.level * wgt * confMul;
    weightSum += wgt * confMul;
  }

  if (weightSum < 0.25) return null; // 有效权重不足
  return Math.round((sum / weightSum / 5) * 100);
}
```

### 记录度 evidence（0–100）

```javascript
function computeEvidence(snapshot) {
  const dims = Object.values(snapshot.dimensions || {});
  if (!dims.length) return null;

  const scores = { documented: 1.0, inferred: 0.65, speculative: 0.35, absent: 0 };
  let total = 0;
  for (const d of dims) {
    total += scores[d.confidence] ?? 0;
  }
  return Math.round((total / dims.length) * 100);
}
```

### 预定义权重常量

```javascript
const STAT_WEIGHTS = {
  mobilization: { politics: 0.35, military: 0.40, production: 0.25 },
  innovation:   { technology: 0.65, culture: 0.35 },
  prosperity:   { economy: 0.55, production: 0.45 },
  stability:    { politics: 0.50, historical_memory: 0.50 },
  livelihood:   { daily_life: 0.55, resources: 0.45 },
  influence:    { military: 0.35, geography: 0.30, economy: 0.35 },
};
```

### 时代均值（对比背景板）

```javascript
function periodAverageStat(year, statId, civilizations, tolerance) {
  const values = civilizations
    .map(civ => nearestSnapshot(civ, year))
    .filter(s => s && Math.abs(s.year - year) <= tolerance)
    .map(s => computeStat(s, STAT_WEIGHTS[statId]))
    .filter(v => v != null);

  if (values.length < 2) return null;
  return Math.round(values.reduce((a, b) => a + b, 0) / values.length);
}
```

## 双雷达 UI 规范

### 视图切换

```
[ 剖面 ]  [ 对比 ]     ← 顶部 Tab
```

| 剖面模式 | 对比模式 |
|----------|----------|
| 十维轴（2 字简称） | 七项派生指标轴（3 字英文或中文简称） |
| 可有缺角 | 尽量满图；`null` 轴标 N/A |
| 卡片 = 十维 summary | 卡片 = 指标值 + 构成展开 |
| 单文明为主 | 支持 2–3 文明叠图 |

### 对比模式图层（底 → 顶）

1. 灰色虚线 — 同期派生指标均值（`n ≥ 2`）
2. 虚线描边 — 第 2、3 文明（最多 3）
3. 实线填充 — 主文明

### 剖面模式：有据 vs 含猜测（可选）

同一文明两条轮廓：

| 轮廓 | 规则 | 画法 |
|------|------|------|
| 实线 | 仅 `documented` + `inferred` 的 level | 不透明 |
| 虚线 | 含 `speculative` 的 level | 半透明 |

`absent` 轴两条都不画顶点。差异 = 猜测撑起了哪些角。

### 顶点样式

| 类型 | 样式 |
|------|------|
| documented / inferred | 实心点 |
| speculative（剖面模式） | 空心点 |
| 派生指标依赖 speculative 过半 | 对比轴旁标 `?` 或降透明度 |

### 无分维度如何比较

| 场景 | 剖面雷达 | 对比雷达 | 卡片 |
|------|----------|----------|------|
| 双方都有 level | 形状对比 | 派生值对比 | 并排摘要 |
| 一方 absent | 缺角 | 派生项可能 N/A | 文字说明 |
| 仅 speculative | 虚线轮廓或空心点 | 降权计入派生值 | 标「猜测」 |

> **有定量比形状，无量比文字，都没有就留空。**

---

## 禁止事项

- 将派生指标写入 `china.json` 替代十维
- 用 `level × confidence` 作为存储字段
- 将 `absent` 当作 0 参与平均
- 对比雷达使用原始十维作轴
- 不标注公式来源就修改权重
