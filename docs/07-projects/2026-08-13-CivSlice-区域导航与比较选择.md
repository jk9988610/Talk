# CivSlice 区域导航与比较选择

> 实现仓库：[CivSlice](https://github.com/jk9988610/CivSlice)  
> **本文件为时间轴交互的 v2 主设计**，取代「全球统一时代段优先」方案。  
> 关联：[时间轴交互流程](2026-08-12-CivSlice-时间轴交互流程.md) · [对比雷达与派生指标](2026-08-12-CivSlice-对比雷达与派生指标.md)

## 核心流程

```
① 区域 → ② 时间段 → ③ 多选国家（泳道） → ④ 段内时间轴 → ⑤ 比较维度勾选
```

| 步骤 | 用户操作 | 系统行为 |
|------|----------|----------|
| ① 区域 | 选七大区域之一 | 加载该区域的国家池与专属时间段列表 |
| ② 时间段 | 选该区域的一个时段 | 收窄时间轴；切换维度集；过滤可用国家 |
| ③ 国家 | 多选加入 / 取消移除 | 选中 → 出现泳道；取消 → 删除泳道 |
| ④ 时间轴 | 拖滑块、点泳道圆点 | 更新当前聚焦快照与剖面雷达 |
| ⑤ 比较 | 勾选参与对比的国家 | 对比雷达仅含勾选国；默认全选 |

---

## ① 区域选择

### 七大区域

| id | 显示名 |
|----|--------|
| `western_europe` | 西欧 |
| `eastern_europe` | 东欧 |
| `middle_east` | 中东 |
| `east_asia` | 东亚 |
| `south_asia` | 南亚 |
| `north_america` | 北美 |
| `south_america` | 南美 |

### 行为

- 切换区域 → **重置** ②③④⑤ 全部选择
- 国家池 = `civilizations` 中 `regions` 含当前区域且有当前段快照的实体
- 一国可属多区域（如土耳其：`middle_east` + 部分 `eastern_europe`）

```json
{
  "id": "china",
  "name": "中国",
  "regions": ["east_asia"],
  "color": "#b22222"
}
```

## ② 时间段（按区域配置）

> **各区域可有不同的时间段划分与标签，不必全球统一模板。**

### 原则

- 时间段列表定义在 `meta.regions[].periods[]`，非全局单一列表
- 每段仍绑定 `eraTemplate`（决定剖面维度集），但 `yearMin`/`yearMax`/`label` 可按区域定制
- 例：中东可有「古代两河」「伊斯兰黄金时代」；东亚可有「春秋战国」「唐宋」

### 数据

```json
{
  "meta": {
    "regions": [
      {
        "id": "east_asia",
        "label": "东亚",
        "periods": [
          {
            "id": "ea_bronze",
            "label": "青铜时代",
            "yearMin": -4000,
            "yearMax": -1000,
            "eraTemplate": "bronze"
          },
          {
            "id": "ea_imperial",
            "label": "帝制时代",
            "yearMin": -221,
            "yearMax": 1912,
            "eraTemplate": "iron_imperial"
          }
        ]
      },
      {
        "id": "middle_east",
        "label": "中东",
        "periods": [
          {
            "id": "me_ancient",
            "label": "古代两河与埃及",
            "yearMin": -3500,
            "yearMax": -500,
            "eraTemplate": "bronze"
          },
          {
            "id": "me_islamic",
            "label": "伊斯兰黄金时代",
            "yearMin": 750,
            "yearMax": 1250,
            "eraTemplate": "iron_imperial"
          }
        ]
      }
    ]
  }
}
```

### 行为

- 选时段 → 重置③④⑤
- 主时间轴 `min`/`max` = 该段 `yearMin`/`yearMax`
- 剖面雷达维度 = 该段 `eraTemplate`
- 顶栏：`东亚 · 帝制时代 · 公元前 221 — 1912`

## ③ 国家多选与泳道

### 国家选择器

- 展示当前**区域 + 时段**内有快照的国家列表
- **多选 Checkbox**：选中加入泳道，取消则从泳道移除
- 无单选限制；可选 0~N 国
- 选 0 国时：泳道区空，主时间轴与雷达显示占位提示

### 泳道规则

```
选中 中国、日本、朝鲜 → 泳道显示 3 行
取消 日本            → 日本泳道消失，日本从比较池移除
```

| 操作 | 泳道 | 比较默认 |
|------|------|----------|
| 勾选国家 | 新增一行 | 该国**自动加入**比较（默认参与） |
| 取消勾选 | 删除该行 | 该国从比较池**移除** |
| 段内圆点 | 不变 | 点击圆点 → ④ 主时间轴聚焦该国该年 |

### 泳道计算

```javascript
function swimlanes(regionId, period, civilizations, selectedCountryIds) {
  return selectedCountryIds
    .map(id => civilizations.find(c => c.id === id))
    .filter(Boolean)
    .map(civ => ({
      id: civ.id,
      name: civ.name,
      color: civ.color,
      markers: civ.snapshots.filter(s =>
        s.year >= period.yearMin && s.year <= period.yearMax
      ),
    }))
    .filter(lane => lane.markers.length > 0);
}
```

## ④ 段内主时间轴

- 范围 = 当前时段 `yearMin` ~ `yearMax`
- **聚焦国**：泳道点击或比较面板选中时的「当前查看」国家（剖面雷达主对象）
- 滑块拖动 → 更新聚焦国在当前段的最近快照
- 与 [泳道总览](2026-08-12-CivSlice-时间轴交互流程.md#②½-各国泳道时间轴阶段内总览) 联动

## ⑤ 比较维度勾选

> 泳道中的国家**默认全部参与**维度比较；可单独取消某国，使其不参与对比雷达，但**泳道保留**（若仍勾选在③）。

### 两层选择（重要）

| 层级 | 控制 | 影响 |
|------|------|------|
| **泳道成员**（③） | 国家 Checkbox | 是否显示泳道行 |
| **比较参与**（⑤） | 比较面板 Toggle | 是否进入对比雷达/派生指标 |

默认：加入泳道 → `comparisonActive` 自动包含该国。

### 比较面板 UI

位于对比视图（或剖面旁栏），泳道国家列表：

```
比较参与：
  [✓] 中国    [✓] 日本    [ ] 朝鲜
       ↑ 点击取消 → 朝鲜仍保留泳道，但对比雷达不画朝鲜多边形
```

| 控件 | 行为 |
|------|------|
| 全选 / 全不选 | 批量切换比较参与 |
| 单击某国 Toggle | 仅影响对比雷达，不删泳道 |
| 对比雷达 | 只绘制 `comparisonActive` 中的国家 |
| 时代均值背景 | 基于 `comparisonActive` 计算（n≥2） |

### 状态模型

```javascript
const uiState = {
  regionId: 'east_asia',
  periodId: 'ea_imperial',
  swimlaneMembers: ['china', 'japan', 'korea'],  // ③ 勾选
  comparisonActive: ['china', 'japan'],           // ⑤ 比较参与（⊆ swimlaneMembers）
  focusCountryId: 'china',                        // ④ 剖面主视图
  focusYear: 1000,
};

// ③ 新加入国家时
function onCountryAddToSwimlane(countryId) {
  swimlaneMembers.push(countryId);
  if (!comparisonActive.includes(countryId)) {
    comparisonActive.push(countryId);  // 默认参与比较
  }
}

// ③ 从泳道移除时
function onCountryRemoveFromSwimlane(countryId) {
  swimlaneMembers = swimlaneMembers.filter(id => id !== countryId);
  comparisonActive = comparisonActive.filter(id => id !== countryId);
}

// ⑤ 仅切换比较参与
function onToggleComparison(countryId) {
  if (comparisonActive.includes(countryId)) {
    comparisonActive = comparisonActive.filter(id => id !== countryId);
  } else if (swimlaneMembers.includes(countryId)) {
    comparisonActive.push(countryId);
  }
}
```

### 对比雷达规则

- 最多同时绘制 **5** 国（可读性上限，超出时提示）
- `comparisonActive` 为空 → 对比雷达显示「请至少选择一国参与比较」
- 剖面雷达（十维）始终显示 **focusCountryId** 的单国快照，不受⑤影响

## 视图分工

| 视图 | 数据范围 | 受⑤影响 |
|------|----------|---------|
| 剖面雷达 | `focusCountryId` 单国 | 否 |
| 对比雷达 | `comparisonActive` 多国 | 是 |
| 泳道 | `swimlaneMembers` | 否（③控制） |
| 维度卡片（剖面） | 聚焦国 | 否 |
| 维度卡片（对比） | 比较参与国并排 | 是 |

## 与旧设计的关系

| 旧（v1） | 新（v2，本文） |
|----------|----------------|
| 全球统一 7 时代段 | **区域** 各自 `periods[]` |

| 对比模式 Checkbox | **⑤ 比较参与 Toggle**，默认全选 |

## 实现优先级

| 阶段 | 内容 |
|------|------|
| P1 | `meta.regions` 七区域 + 每区域 `periods` |
| P2 | ①② 区域/时段 Tab，切换重置下游 |
| P3 | ③ 国家多选 ↔ 泳道增删 |
| P4 | ④ 主时间轴 + 泳道圆点联动 |
| P5 | ⑤ 比较参与 Toggle + 对比雷达过滤 |
| P6 | 文明 `regions[]` 字段、跨国多区域 |
| P7 | localStorage 记忆选择 |

---

## 禁止事项

- 全球强制同一时间段列表（须按区域配置）
- 未选区域即加载国家/泳道
- 从泳道移除却仍在 `comparisonActive` 中
- 对比雷达包含未在 `comparisonActive` 中的国家
- 剖面雷达同时叠超过 1 国（剖面始终单国聚焦）
