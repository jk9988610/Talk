# 文档总览

本目录按主题归类所有交流文档。每篇文档建议使用 [frontmatter 元数据](../CONTRIBUTING.md#文档元数据) 标注分类、标签与状态。

## AI 助手入口

若在 Cursor 或其他 AI 环境中工作，请先阅读 **[AI-GUIDE.md](AI-GUIDE.md)** — 含仓库定位、CivSlice / MiraSpace 协作规范与新对话启动模板。

## 分类体系

```
docs/
├── 01-ideas/          想法速记 — 灵感、碎片、待展开
├── 02-essays/         随笔 — 完整表达的观点与叙述
├── 03-tech/           技术 — 编程、架构、工具、实践
├── 04-philosophy/     哲学思辨 — 认识、伦理、存在
├── 05-life/           生活感悟 — 日常、习惯、体验
├── 06-reading/        读书笔记 — 摘要、批注、延伸
├── 07-projects/       项目构想 — 产品、开源、实验
├── 08-discussions/    开放讨论 — 命题、辩题、待回应
└── 99-archive/        归档 — 已完结或过时内容
```

## 分类选择指南

| 你的内容… | 推荐目录 |
|-----------|----------|
| 只有几句话、尚未成文 | [01-ideas](01-ideas/) |
| 已经写成完整文章 | [02-essays](02-essays/) |
| 关于代码、系统、工程 | [03-tech](03-tech/) |
| 关于真理、价值、意义 | [04-philosophy](04-philosophy/) |
| 关于日常生活与个人成长 | [05-life](05-life/) |
| 围绕某本书展开 | [06-reading](06-reading/) |
| 描述一个想做的产品或项目 | [07-projects](07-projects/) |
| 想发起讨论、征集观点 | [08-discussions](08-discussions/) |
| 内容已过时或不再维护 | [99-archive](99-archive/) |

## 文档状态

| 状态 | 含义 |
|------|------|
| `draft` | 草稿，结构或观点尚不完整 |
| `review` | 待审阅，欢迎评论与修改建议 |
| `published` | 已发布，内容相对稳定 |
| `archived` | 已归档，移至 `99-archive/` |
